    绪论：从「实现者」到「设计师」

    这一讲回答「为什么学算法」。核心不是记住代码，而是建立先设计、后实现的习惯： 用伪代码理清思路，用抽象把现实问题映射到已知计算模型，用复杂度分析判断方案好坏，用正确性证明给自己的设计背书。

    四大思维陷阱与四大核心武器

    课程开篇用四个「思维陷阱」点出常见误区，并对应给出四件「核心武器」。这两组是本讲的纲领，考试常以简答形式出现。

    四大思维陷阱

    陷阱现象与根源课程给出的对策
    代码先行，思维滞后 打开 IDE 就开始写代码，调试代替思考；混淆「实现」与「设计」。不经设计的编码是最高成本的调试。 先思考 → 选算法 → 分析复杂度 → 设计伪代码 → 再编码。例：线性时间选择，不要一上来冒泡排序取第 k 个（O(n²)），而应搜索到快速选择 QuickSelect（平均 O(n)）。
    缺乏抽象，无法形式化 困在问题表面，看不到计算本质。现实问题虽复杂，但计算模型是有限的。 把具体问题映射到已知模型（图、树、集合）。例：社交网络「最短好友链」→ 识别实体为顶点、关系为边 → 无权图最短路径 → BFS。
    不善于检索，重复造轮子 不知道已有优秀解法，写出低效甚至充满漏洞的代码。 例：最长公共子序列（LCS）。自己枚举子序列是 O(n·2m)；已经存在动态规划解法——理解最优子结构与公共子问题，站在巨人肩膀上。
    证明缺失，盲目自信 「感觉可行」是算法设计中最危险的一句话。没有严格数学证明，算法只是「猜想」。 例：区间调度（安排尽可能多的不重叠会议）。直觉方案「选最早开始的」会被「最早开始但开一整天」的会议堵死；正确方案是选最早结束的，并必须证明贪心选择性质与最优子结构。

    四大核心武器

    武器要点
    ① 伪代码 —— 设计的蓝图 设计与实现之间存在鸿沟。伪代码用自然语言与代码结构的混合体描述逻辑，忽略语法细节，聚焦流程、条件、循环。配套工程习惯：测试驱动（先写测试用例定义边界）、模块化与接口化（先定 partition(arr, low, high) 声明再实现）、增量实现与验证、防御性编程。
    ② 建模与抽象 通过模式识别训练：课程系统讲解经典算法范式（分治、动态规划、贪心、回溯、分支限界），每个范式配多个问题演示如何抽象与建模。
    ③ 分析与证明 时间复杂度（大 O 等记号、最坏/平均/最好情况）、正确性证明（循环不变式、数学归纳法、反证法）、求解递归式、最优子结构、贪心选择性质。
    ④ 资源检索与利用 把问题转化为搜索关键词（「最短好友链」→「无权图最短路径 BFS」）；善用公开课、代码仓库与在线工具书。

    考点归纳

    四个陷阱与四件武器是一一对应的：代码先行 → 伪代码；缺乏抽象 → 建模与抽象；重复造轮子 → 资源检索；证明缺失 → 分析与证明。

    计算思维

    2006 年 3 月，周以真（Jeannette M. Wing，时任卡内基·梅隆大学计算机系系主任）首次提出 计算思维（Computational Thinking）的概念：运用计算机科学的基础概念去求解问题、设计系统和理解人类的行为， 它涵盖了计算机科学之广度的一系列思维活动。

    2010 年她进一步指出：计算思维是与形式化问题及其解决方案相关的思维过程， 其解决问题的表示形式应该能有效地被信息处理代理执行。

    计算思维吸取了一般数学思维的解决问题方法、现实世界中巨大复杂系统的设计与评估的一般工程思维方法， 以及理解复杂性、智能、心理与人类行为的一般科学思维方法。它是数学思维与工程思维的互补与融合： 抽象与实现。

    算法的历史起点：辗转相除法

    约公元前 300 年，欧几里德在《几何原本》中给出辗转相除法（Euclidean algorithm）， 用于计算两个整数的最大公约数（GCD, Greatest Common Divisor）。 它被公认为最早的「算法」之一：有明确的输入输出、有限步终止、每步无歧义。

    算法思想

    核心恒等式：gcd(m, n) = gcd(n, m mod n)。 反复用除数替换被除数、用余数替换除数，直到余数为 0，此时除数即为最大公约数。

    图 1-2　辗转相除法流程图：循环体把 (m, n) 替换为 (n, m mod n)，直至余数为 0

    伪代码与 C++ 实现

    伪代码

    EUCLID(m, n)                      // 求 gcd(m, n)，要求 m、n 为非负整数
1  while n ≠ 0                  // 只要除数 n 不为 0 就继续循环
2      r = m mod n                // 求 m 除以 n 的余数 r
3      m = n                      // 用原来的除数替换被除数
4      n = r                      // 用余数替换除数（问题规模缩小）
5  return m                       // 循环结束时 n = 0，m 即最大公约数

    C++

    // 辗转相除法（迭代版）：返回 a 与 b 的最大公约数
long long gcd(long long a, long long b) {   // 参数 a、b 为非负整数，返回 gcd(a, b)
    while (b != 0) {              // 只要除数 b 不为 0 就继续循环
        long long r = a % b;      // 求 a 除以 b 的余数 r
        a = b;                    // 用原来的除数替换被除数
        b = r;                    // 用余数替换除数，问题规模严格缩小
    }
    return a;                     // 循环结束时 b == 0，a 即最大公约数
}
// 递归版写法（与迭代版完全等价，便于对照数学恒等式）
long long gcdRec(long long a, long long b) {   // 递归求解 gcd(a, b)
    if (b == 0) return a;         // 递归出口：余数为 0 时返回被除数
    return gcdRec(b, a % b);      // 否则 gcd(a,b) = gcd(b, a mod b)
}

    辗转相除法执行过程

    复杂度分析

    辗转相除法的循环次数与 n 的位数成正比。 可以证明：每两次迭代后，较大的数至少减半（因为 r < n 且 m mod n < m/2 在两步之内成立）， 因此迭代次数为 O(log min(m, n))。设输入规模为数字的位数 k，则时间复杂度为 O(k)，即线性于输入位数。

    T(m, n) = O(log min(m, n)) = O(k)，其中 k 为输入整数的位数

    考点归纳

    辗转相除法是「算法」最早的代表：满足有穷性（余数严格递减，必到 0）、 确定性（每步唯一确定）、可行性（只做取余与赋值）。

    线性时间选择：找第 k 小的元素

    问题描述：给定线性序集中 n 个元素和一个整数 k， 要求找出这 n 个元素中第 k 小的元素。

    课程用它作为「代码先行 vs 先设计」的对比案例：同一问题有五种层次递进的解法。

    解法思路复杂度点评
    解法 1：暴力法对每个元素统计比它小的个数O(n²)不需要排序，但代价高
    解法 2：归并排序完全排序后取第 k 个O(n log n)稳定，但做了大量无用功
    解法 3：快速排序完全排序后取第 k 个平均 O(n log n)同样只有「部分排序」需求
    解法 4：期望线性时间选择快速选择 QuickSelect，只递归一侧平均 O(n)本讲重点
    解法 5：最坏线性时间选择中位数的中位数（BFPRT）最坏 O(n)保证划分均衡

    特殊情况：k = 1 或 k = n

    求最小值或最大值只需一次线性扫描，记录当前最小/最大元素即可，比较次数为 n − 1。

    特殊情况：同时找最小值和最大值

    一个图形程序可能需要转换一组坐标数据 (x, y) 以适配矩形显示器，因此必须先确定每个坐标的最小值与最大值。两种做法：

    1. 分别独立地找出最小值与最大值：共需 2n − 2 次比较。
    2. 成对处理输入元素：先把一对输入元素相互比较（1 次），再把较小的与当前最小值比较、较大的与当前最大值比较（2 次），即每两个元素共需 3 次比较。总计 3⌊n/2⌋ 次。

    成对处理比较次数 = 3⌊n/2⌋  <  2n − 2  （n ≥ 2 时）

    期望线性时间选择：快速选择 QuickSelect

    与快速排序共用 PARTITION，但每层只递归一侧： 划分后基准落到正确位置 q，若 k = q 直接返回； 若 k < q 只需在左半段继续找第 k 小；否则在右半段找第 k − q 小。 期望时间 T(n) = T(n/2) + O(n) = O(n)。

    伪代码（快速选择）

    RANDOMIZED-SELECT(A, p, r, k)     // 在 A[p..r] 中找第 k 小的元素（k 从 1 开始计数）
1  if p == r                      // 区间只剩一个元素，它必然就是答案
2      return A[p]                 // 直接返回该元素
3  q = RANDOMIZED-PARTITION(A, p, r)  // 随机选基准划分，返回基准最终下标 q
4  i = q - p + 1                  // 基准在「本区间内」是第 i 小的元素
5  if k == i                      // 情况一：基准恰好就是第 k 小
6      return A[q]                 // 直接返回基准
7  else if k < i                   // 情况二：第 k 小落在左半段
8      return RANDOMIZED-SELECT(A, p, q - 1, k)      // 只递归左侧，k 不变
9  else                            // 情况三：第 k 小落在右半段
10     return RANDOMIZED-SELECT(A, q + 1, r, k - i)  // 只递归右侧，k 减去左半段长度

    C++

    // Lomuto 划分：以 A[r] 为基准，返回基准最终所在下标
int partition(int A[], int p, int r) {   // 参数：数组 A、区间左端 p、右端 r
    int x = A[r];                 // 取区间最后一个元素作为基准 pivot
    int i = p - 1;                // i 指向「小于等于基准」区域的最后一个位置
    for (int j = p; j < r; ++j) { // j 从左到右扫描整个区间（不含基准本身）
        if (A[j] <= x) {          // 当前元素不大于基准，应归入左区
            ++i;                  // 左区右边界右移一格
            std::swap(A[i], A[j]); // 把 A[j] 换到左区末尾
        }
    }
    std::swap(A[i + 1], A[r]);    // 把基准换到左右区之间，即它的最终位置
    return i + 1;                 // 返回基准下标
}
// 快速选择：返回 A[p..r] 中第 k 小的元素（k 从 1 开始）
int quickSelect(int A[], int p, int r, int k) {   // 参数：数组 A、区间 [p, r]、目标序号 k（1 起）
    if (p == r) return A[p];      // 区间只剩一个元素，直接就是答案
    int q = partition(A, p, r);   // 划分，基准落到最终位置 q
    int i = q - p + 1;            // 基准在区间内排第 i 小
    if (k == i) return A[q];      // 命中：基准就是第 k 小
    if (k < i)                    // 第 k 小在左半段
        return quickSelect(A, p, q - 1, k);            // 只递归左侧
    return quickSelect(A, q + 1, r, k - i);            // 否则递归右侧，k 扣除左半段
}
    快速选择：数组中第 k 小的元素

    易错点

    第 5 行的比较是 k = i 而不是 k = q。 q 是原数组下标，i = q − p + 1 才是基准在当前区间内的序号。 递归右半段时 k 要减去 i，因为左半段那 i 个元素整体都比目标小。

    分而治之：快速排序

    快速排序是本课程分治法（Divide and Conquer）的第一个完整示范。对 n 个项的数组：

    • 分解：围绕基准 x 将数组划分成两个子数组，使左边子数组中的项 ≤ x，右边子数组中的项 ≥ x。
    • 解决：递归地对两个子数组排序。
    • 合并：很简单（原址排序，无需合并操作）。

    关键：线性时间的划分函数 PARTITION。

    图 1-3　快速排序的分解：划分后基准 x 落在最终位置，左右两段各自递归

    伪代码与 C++ 实现

    伪代码

    QUICKSORT(A, p, r)                // 对子数组 A[p..r] 原地升序排序
1  if p < r                        // 区间内至少有两个元素才需要排序
2  then q = PARTITION(A, p, r)     // 划分，返回基准最终下标 q
3       QUICKSORT(A, p, q - 1)     // 递归排序左半段（都 ≤ 基准）
4       QUICKSORT(A, q + 1, r)     // 递归排序右半段（都 ≥ 基准）
                                  // 直接调用：QUICKSORT(A, 1, n)
PARTITION(A, p, q)                // 划分 A[p..q]，返回基准最终下标
1  x = A[p]                       // 取区间第一个元素作为基准 pivot
2  i = p                          // i 指向「≤ x 区域」的最后一个位置
3  for j = p + 1 to q             // j 从左到右扫描「未处理区域」
4  do if A[j] ≤ x               // 当前元素不大于基准，应并入左区
5        then i = i + 1           // 左区右边界右移一格
6             exchange A[i] ↔ A[j]   // 把 A[j] 换到左区末尾
7  exchange A[p] ↔ A[i]       // 把基准换到左右区交界处，即最终位置
8  return i                        // 返回基准下标

    C++

    // 划分函数（对应 PPT 的 PARTITION(A, p, q)）：以 A[p] 为基准
int partition(int A[], int p, int q) {   // 参数：数组 A、区间左端 p、右端 q
    int x = A[p];                 // 取区间第一个元素作为基准 pivot
    int i = p;                    // i 指向「小于等于基准」区域的最后一个位置
    for (int j = p + 1; j <= q; ++j) {  // j 从左到右扫描未处理区域
        if (A[j] <= x) {          // 当前元素不大于基准，归入左区
            ++i;                  // 左区右边界右移一格
            std::swap(A[i], A[j]); // 把它换到左区末尾
        }
    }
    std::swap(A[p], A[i]);        // 把基准换到左右区交界，即最终位置
    return i;                     // 返回基准下标
}
// 快速排序主过程：对 A[p..r] 升序排序
void quickSort(int A[], int p, int r) {   // 参数：数组 A、待排序区间 [p, r]
    if (p < r) {                  // 至少两个元素才需要排序
        int qq = partition(A, p, r);  // 划分并取得基准最终下标
        quickSort(A, p, qq - 1);  // 递归排序左半段
        quickSort(A, qq + 1, r);  // 递归排序右半段
    }
}

    划分过程演示

    以课程PPT的例子数组 6, 10, 13, 5, 8, 3, 2, 11 为例，基准 x = A[p] = 6。 划分过程中维持一个循环不变式：A[p..i] ≤ x、A[i+1..j−1] > x、A[j..q] 未处理。 详细的逐帧演示见「L1 · 算法基础与分析」页的 partition 动画。

    图 1-4　PARTITION 的三段式区间划分：每次 A[j] ≤ x 就扩张左区一格

    复杂度分析

    情形划分结果递归式复杂度
    最坏情况 每次划分极不平衡（如已排序且总取首元素为基准），一侧为空 T(n) = T(n−1) + O(n) Θ(n²)
    最好情况 每次划分恰好平分 T(n) = 2T(n/2) + O(n) Θ(n log n)
    平均情况 随机基准，期望划分较均衡 T(n) = O(n log n) Θ(n log n)

    划分函数本身只需一次线性扫描与常数次交换，故 PARTITION 的时间为 O(n)。 随机化选取基准可以避免「已排序输入」这一最坏实例，把最坏情况的概率降到可忽略。

    考点归纳

    分治三步：分解（Divide）→ 解决（Conquer）→ 合并（Combine）。 快速排序的合并步骤是「很简单」（原址、无额外工作），归并排序的合并步骤是「线性时间合并」。 两者的差异决定了：快排的关键在划分，归并的关键在合并。

    抽象与建模：三个经典例子

    「缺乏抽象」是四大陷阱之一。抽象的本质是把具体问题映射到已知计算模型（图、树、集合）， 从而把「无从下手」变成「直接应用经典算法」。课程给出三个例子。

    例 1：澳大利亚地图染色问题

    用红、绿、蓝 3 种颜色标出各省，要求相邻省份颜色不同。 抽象方法：每个省作为一个顶点，相邻关系作为边，得到约束图； 问题转化为图的 3-着色，可用回溯法求解。

    图 1-5　澳大利亚地图染色问题对应的约束图：7 个顶点、9 条边，配色为一组可行解

    例 2：素数环问题

    问题：针对一个整数 n，把从 1 到 n 的数字无重复地排列成环， 且使每相邻两个数（包括首尾）的和都为素数，则称为素数环。

    按课程的三个提问回答：

    1. 建模：顶点集 V = {1, 2, …, n}； 若 i + j 为素数则连边 (i, j)，得到一张无向图。 素数环就是该图中的一条哈密顿回路（经过每个顶点恰好一次的回路）。
    2. 算法：回溯法。按位置 1..n 逐个放置数字， 每放一个就检查「与前一位置之和为素数」且「该数字未被使用」；放满 n 个后再检查首尾之和是否为素数。

    PRIME-RING(n)                     // 求 1..n 的素数环，n 为偶数时才有解
1  used[1..n] = false              // used[i] 标记数字 i 是否已被放入环中
2  a[1] = 1; used[1] = true        // 固定起点为 1（环可旋转，固定起点可剪掉等价解）
3  BACKTRACK(2)                    // 从第 2 个位置开始递归尝试放置
                                  // 搜索结束后，所有合法解都已在 BACKTRACK 内输出

BACKTRACK(pos)                    // pos 为当前待放置的位置
1  if pos > n                      // 已放满 n 个位置
2  then if IS-PRIME(a[n] + a[1])   // 关键：检查首尾之和是否也为素数
3       then 输出环 a[1..n]        // 得到一个合法解
4       return                     // 该分支结束
5  for v = 2 to n                  // 依次尝试每个未使用的数字 v
6  do if not used[v] and IS-PRIME(a[pos-1] + v)   // 剪枝：未用过且与前一数之和为素数
7        then used[v] = true       // 标记 v 已使用
8             a[pos] = v           // 把 v 放到当前位置
9             BACKTRACK(pos + 1)   // 递归放置下一个位置
10            used[v] = false      // 回溯：撤销标记，尝试下一个候选

    C++

    const int MAXN = 20;              // 最大规模 n 的上限（环上最多 20 个数）
int n, a[MAXN];                   // a[] 保存当前正在构造的环
bool used[MAXN];                  // used[i]：数字 i 是否已被放入环中

// 判断 x 是否为素数（试除法，x 为两个不超过 n 的数之和，规模很小）
bool isPrime(int x) {             // 判断 x 是否为素数，返回 true/false
    if (x < 2) return false;      // 小于 2 的数不是素数
    for (int d = 2; d * d <= x; ++d)  // 只需试除到 sqrt(x)
        if (x % d == 0) return false; // 找到因子，不是素数
    return true;                  // 没有因子，是素数
}

// 回溯：尝试为第 pos 个位置选一个数字
void backtrack(int pos) {         // 参数 pos：当前正在填的位置（从 2 开始）
    if (pos > n) {                // 已放满 n 个位置
        if (isPrime(a[n] + a[1])) {  // 关键：检查首尾之和是否为素数
            for (int i = 1; i <= n; ++i) printf("%d ", a[i]);  // 输出一个合法环
            printf("\n");         // 换行
        }
        return;                   // 该分支结束
    }
    for (int v = 2; v <= n; ++v) { // 依次尝试每个候选数字
        if (!used[v] && isPrime(a[pos - 1] + v)) {  // 剪枝条件
            used[v] = true;       // 标记已使用
            a[pos] = v;           // 放到当前位置
            backtrack(pos + 1);   // 递归放置下一个位置
            used[v] = false;      // 回溯：撤销标记
        }
    }
}

int main() {                      // 程序入口，构造 n = 8 的素数环实例
    n = 8;                        // 以 n = 8 为例
    a[1] = 1; used[1] = true;     // 固定起点为 1，剪掉环的旋转等价解
    backtrack(2);                 // 从第 2 个位置开始搜索
    return 0;                     // 正常结束
}

    关键点

    素数环的两处「环」特性必须处理：① 首尾相邻，所以放满后要额外检查 a[n] + a[1]； ② 环可以旋转，所以固定 a[1] = 1 剪掉 n 倍等价解。 另外 n 为奇数时无解（除 n = 1），可作为入口剪枝。

    例 3：传教士和野人问题

    问题：设有 3 个传教士和 3 个野人来到一条河的左岸，打算乘一只船从左岸渡到右岸。 船的负载能力为 2 人。在任何时候，如果野人人数超过传教士人数，野人就会把传教士吃掉。 野人绝对服从传教士的指挥和调度。

    状态表示：用三元组 (m, w, B) 表示， 其中 m 为左岸传教士人数、w 为左岸野人数、B = 1 表示船在左岸（B = 0 表示船在右岸）。

    例 4：一般的传教士和野人问题

    有 N 个传教士和 N 个野人来到河边准备渡河，河岸有一条船， 每次至多可供 K 人乘渡。问传教士为了安全起见，应如何规划摆渡方案， 使得任何时刻，在河的两岸以及船上的野人数目总是不超过传教士的数目， 但允许在河的某一岸只有野人而没有传教士。

    设 N = 5、K ≤ 3。在某一时刻，左岸传教士人数用 M 表示、 野人数用 C 表示；B = 1 表示船在左岸，B = 0 表示船在右岸。 与 3+3 版本相比，一般版本的约束放宽为「允许某一岸只有野人」，状态空间更大，同样用搜索求解。
