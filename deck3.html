算法分析基础：渐近记号、求解递归式与循环不变式

本讲围绕四件事：① 渐进复杂性的直观含义；② Θ / O / Ω / 小 o / 小 ω 五个渐近记号的严格定义与相互性质；③ 求解递归式的三种技术 —— 代换法、递归树、主方法；④ 用循环不变式证明插入排序的正确性。所有定义、取值与例题均按课程 PPT 的公式原图逐条核对。

1. 渐进复杂性：只看增长量级

当输入规模大到"只与运行时间的增长量级有关"时，就需要研究算法的渐进效率 (asymptotic efficiency)。从极限角度看，我们只关心算法运行时间如何随着输入规模的无限增长而增长；通常对不是很小的输入规模而言，渐进意义上更有效的算法才是最佳选择。

定义：渐进性态 / 渐进复杂性

设 T(N) 是算法 A 的复杂性函数。一般说来，当 N 单调增加且趋于 ∞ 时，T(N) 也将单调增加趋于 ∞。如果存在 T′(N)，使得当 N→∞ 时

( T(N) − T′(N) ) / T(N) → 0

那么就说 T′(N) 是 T(N) 当 N→∞ 时的渐进性态，或称 T′(N) 为算法 A 当 N→∞ 时的渐进复杂性。

直观理解：T′(N) 是 T(N) 中略去低阶项所留下的主项，形式更简洁，却抓住了增长的本质。

例：T(N) = 3N2 + 4N·logN + 7，则 T′(N) = 3N2。验算比值确实趋于 0：

(T(N) − T′(N)) / T(N) = ( 4N·logN + 7 ) / ( 3N2 + 4N·logN + 7 ) → 0  (N→∞)

记忆

渐进分析只需两步：先只保留增长最快的那一项，再丢掉它的常数系数。低阶项与常数在 N 足够大时都会被"淹没"。

本讲的知识框架（对应 PPT 第 1 章 §1.4～§1.5）：渐进复杂性 → 渐进记号（Θ / O / Ω / o / ω）→ 渐进表示法（等式约定与运算规则）→ 渐进函数之间的比较性质；随后进入求解递归式（代换法 / 递归树 / 主方法）与算法正确性证明（循环不变式）。

2. Θ 记号：渐进确界（紧致界）

渐近记号用来表示算法的渐近运行时间，定义域为自然数集合 N（n 表示 Size），有时也扩展到实数或限制到自然数的某子集上。

定义（Θ 记号，渐进确界 / 紧致界）

给定一个函数 g(n)，Θ(g(n)) 表示一个函数的集合：

Θ(g(n)) = { f(n) | ∃ 常数 c1, c2, n0 > 0，使得对所有的 n ≥ n0 有：
0 ≤ c1g(n) ≤ f(n) ≤ c2g(n) }

即 f(n) ∈ Θ(g(n)) 表示：存在正常数 c1、c2 及足够大的 n0，使得 f(n) 被夹在 c1g(n) 和 c2g(n) 之间。

对所有的 n ≥ n0，函数 f(n) 在一个常数因子范围内等于 g(n)，则称 g(n) 是 f(n) 的一个渐近紧致界，即 g(n) 既是 f(n) 的渐近上界，又是 f(n) 的渐近下界。这里 f(n) 是算法的计算时间，g(n) 是算法时间的数量级。

易错

① Θ 定义中要求 f(n) 和 g(n) 是渐近非负的，否则 Θ(g(n)) 是空集；
② 不同的输入实例，一个算法的计算时间 f(n) 不一定相同，所以"算法的计算时间"本身是一个函数集合，这正是要用集合记号的原因。

图 1  Θ 记号：g(n) 在一个常数因子范围内等于 f(n)，既是渐近上界又是渐近下界

2.1 用定义验证两个小例子

例 1：f(n) = ½ n(n − 1)，证明 f(n) = Θ(n2)。
证明：令 g(n) = n2，就是要找到两个正常数 C1 和 C2，满足 C1g(n) ≤ f(n) ≤ C2g(n)。取 C1 = 1/4、C2 = 1/2、n0 = 2：当 n ≥ 2 时 ½n(n−1) ≥ ½n·(n/2) = n2/4，且 ½n(n−1) < ½n2，两式同时成立。

例 2：f(n) = ½ n2 − 3n，证明 f(n) = Θ(n2)。
证明：仍要证 C1n2 ≤ f(n) ≤ C2n2。取 C1 = 1/4、C2 = 1/2：n ≥ 12 时 ½n2 − 3n ≥ ½n2 − n2/4 = n2/4；而 ½n2 − 3n ≤ ½n2 恒成立。故 n0 = 12 即可。

2.2 一般二次多项式：T(n) = an2 + bn + c（a > 0）

PPT 给出结论 T(n) = Θ(n2)，并直接给出了三个常数（务必记住这组取值）：

c1 = a/4，  c2 = 7a/4，  n0 = 2·max( |b|/a , √(|c|/a) )

推导思路（PPT 备注中的证明）：当 n > n0 时，由 n0 ≥ 2|b|/a 得 n > 2|b|/a，即 an2/2 > |b|n；又由 n0 ≥ 2√(|c|/a) 得 n2 > 4|c|/a，即 an2/4 > |c|n。于是：

an2 + bn + c ≥ an2 − |b|n − |c| ≥ an2 − an2/2 − an2/4 = an2/4 = c1n2

an2 + bn + c ≤ an2 + |b|n + |c| ≤ an2 + an2/2 + an2/4 = 7an2/4 = c2n2

两式合起来就是 0 ≤ c1n2 ≤ an2 + bn + c ≤ c2n2，对所有的 n ≥ n0 成立，故 T(n) = Θ(n2)。

记号 Θ(1) 的含义

Θ(1) 表示算法的运行时间与问题规模 n 无关；也可理解为 Θ(n0) —— 因为任何常数都是 0 次多项式。

3. O 记号：渐进上界

定义（O 记号，渐进上界）

给定一个函数 g(n)，O(g(n)) 表示一个函数的集合：

O(g(n)) = { f(n) | ∃ 常数 c, n0 > 0，使得对所有的 n ≥ n0 有：
0 ≤ f(n) ≤ c·g(n) }

即在一个常数因子范围内 g(n) 是 f(n) 的渐近上界。O(1) 表示常量。

图 2  O 记号：g(n) 是 f(n) 的渐近上界，但界可以是紧的，也可以很松

3.1 两个证明示例（关键是把 c 和 n0 构造出来）

例 3：证明 f(n) = an + b = O(n)，其中 a > 0。
证明：即要证存在正常数 C，使 f(n) = an + b ≤ Cn。取 C = a + |b|、n0 = 1：对一切 n ≥ 1，有

an + b ≤ an + |b| ≤ an + |b|n = (a + |b|)n = Cn

故 f(n) = an + b = O(n)。

例 4：证明 f(n) = 2n2 + n = O(n3)。
证明：即要找到一个正常数 C 使得 f(n) ≤ Cn3。取 C = 3、n0 = 1：当 n ≥ 1 时 n2 ≤ n3 且 n ≤ n3，于是

2n2 + n ≤ 2n3 + n3 = 3n3

故 2n2 + n = O(n3)。注意这个上界并不紧（真正的紧界是 n2 阶），大 O 允许"松"。

3.2 Θ 强于 O，以及 O 与 Θ 的关键区别（常考）

因为 Θ(g(n)) ⊆ O(g(n))，所以 f(n) = Θ(g(n)) ⇒ f(n) = O(g(n))。即 Θ 记号强于 O 记号。

最容易被问倒的一点

· O 描述上界：当用于界定一个最坏运行时间时，蕴含着该算法在任意输入上的运行时间都囿于此界；
· Θ 则不然：一个算法的最坏运行时间是 Θ(g(n))，并不蕴含该算法对每个输入实例的运行时间均囿于 Θ(g(n))。

最经典的例子 —— 插入排序：当输入初始有序时，它的运行时间是 Θ(n) 而不是 Θ(n2)，但 O(n2) 对任何输入实例都成立。原因是：

n = O(n2) 且 n2 = O(n2) 均成立； 但  n2 = Θ(n2) 而 n ≠ Θ(n2)

所以当说"算法的运行时间上界是 O(n2)"时，往往指的就是它的最坏运行时间，无须修饰语 —— 这对那些最好、最坏、平均时间数量级不同的算法同样成立；而用 Θ 时则必须分开表达、加上"最好 / 最坏 / 平均"的修饰语。

4. Ω 记号：渐进下界

定义（Ω 记号，渐进下界）

对给定函数 g(n)，Ω(g(n)) 是一个函数集合：

Ω(g(n)) = { f(n) | ∃ 常数 c, n0 > 0，使得对所有的 n ≥ n0 有：
0 ≤ c·g(n) ≤ f(n) }

意义：对所有 n ≥ n0，f(n) 在 c·g(n) 的上方，即在一个常数因子范围内 g(n) 是 f(n) 的渐近下界。

图 3  Ω 记号：g(n) 是 f(n) 的渐近下界

例 5：证明 f(n) = 3n2 = Ω(n)。
证明：即要证存在正常数 C 使 Cn ≤ 3n2。取 C = 1、n0 = 1：对一切 n ≥ 1 有 n ≤ 3n2，成立，故 3n2 = Ω(n)。

定理 1.1

对任意函数 f(n) 和 g(n)，f(n) = Θ(g(n)) 当且仅当 f(n) = O(g(n)) 且 f(n) = Ω(g(n))。

即：g(n) 是 f(n) 的渐紧界，当且仅当 g(n) 既是 f(n) 的渐近上界又是 f(n) 的渐近下界。这条定理就是把"紧界"拆成"上界 + 下界"来证的标准套路。

当用 Ω 来界定一个算法最好情况下的运行时间时，蕴含着该算法在任意输入上的运行时间都囿于此界（不低于它）。

例：插入排序的下界是 Ω(n)，对任何实例成立（即插入排序的最好运行时间是 Ω(n)）。因为 n = Ω(n)、n2 = Ω(n) 都成立，所以无论输入有序还是逆序，运行时间都不会低于 n 的量级。

5. 小 o 记号：渐近非紧上界

定义（小 o 记号，渐近非紧上界）

o(g(n)) = { f(n) | ∀ 常数 c > 0，∃ 常数 n0 > 0，使得对所有的 n ≥ n0 有：
0 ≤ f(n) < c·g(n) }

注意这里常数 c 是任意的（∀ 而不是 ∃），这是小 o 与大 O 的唯一差别。

直观上，当 n→∞ 时 f(n) 相对于 g(n) 是可忽略的，即 f(n) = o(g(n)) 蕴含着

limn→∞ f(n)/g(n) = 0

只要 n 足够大，g(n) 就是 f(n) 的上界；或者说 f 和 g 的数量级不同 —— 否则不可能对任意常数 c 都有 c·g(n) 严格大于 f(n)。

图 4  小 o 记号：任意常数倍都压不住 f(n)，说明 f 的量级严格小于 g

大 O 与小 o 的对比：大 O 表示的渐近上界可以是渐近紧致的，也可以是渐近非紧的。

等式比值 f(n)/g(n)界的性质
2n2 = O(n2)2n2/n2 → 2（常数）紧致界（其实 2n2 = Θ(n2)）
2n = O(n2)2n/n2 → 0非紧致界（2n = o(n2)）

所以：2n = o(n2)，但 2n2 ≠ o(n2)。

6. 小 ω 记号：渐近非紧下界

定义（小 ω 记号，渐近非紧下界）

ω(g(n)) = { f(n) | ∀ 常数 c > 0，∃ 常数 n0 > 0，使得对所有的 n ≥ n0 有：
0 ≤ c·g(n) < f(n) }

即：对任意常数 c > 0，c·g(n) 对足够大的 n 都要严格小于 f(n)。因此 g 和 f 必定不是同数量级，即 f 的量级 > g 的量级。等价的极限形式：

f(n) = ω(g(n)) ⇒ limn→∞ f(n)/g(n) = ∞

图 5  小 ω 记号：g 的任意常数倍最终都被 f 甩在下面

PPT 给出的例子：n2/2 = ω(n)，但 n2/2 ≠ ω(n2) —— 因为 lim (n2/2)/n = ∞，而 lim (n2/2)/n2 = 1/2（有限常数，同阶，属于 Θ）。

7. 极限比较法与渐近记号的性质

7.1 利用极限比较函数间的增长速度

对于函数 f(n)、g(n)，令 L = limn→∞ f(n)/g(n)，则按下表判定：

极限 L 的值大小关系渐近记号结论含义
0f(n) < g(n)f(n) = o(g(n))f 增长得慢，数量级更小
有限正常数 Cf(n) = g(n)（同阶）f(n) = Θ(g(n))只差一个常数因子
∞f(n) > g(n)f(n) = ω(g(n))f 增长得快，数量级更大

例 6：f(n) = ½ n(n − 1)，g(n) = n2。因为 lim f(n)/g(n) = 1/2（有限正常数），故 f(n) = Θ(n2) —— 与例 1 的结论一致。

例 7：f(n) = lg n，g(n) = √n。因为 lim lg n / √n = 0，故 lg n = o(√n)。

许多实数的关系性质都可以用到渐近比较上（以下假定 f(n) 和 g(n) 都是渐近正的）：

传递性 f(n) = Θ(g(n)) 且 g(n) = Θ(h(n)) ⇒ f(n) = Θ(h(n))

f(n) = Ω(g(n)) 且 g(n) = Ω(h(n)) ⇒ f(n) = Ω(h(n))

7.3 并非所有函数都渐近可比较

思考：是否所有函数都是渐近可比较的？不是。对某些 f(n) 和 g(n)，可能 f(n) = O(g(n)) 不成立，而且 f(n) = Ω(g(n)) 也不成立，从而由定理 1.1 得 f(n) ≠ Θ(g(n))。

例：函数 n 和 n1+sin n 之间是无法渐进比较的。因为 1 + sin n ∈ [0, 2]，即 n1+sin n 在 O(1) ～ O(n2) 之间不断波动，找不到固定的数量级。

8. 渐进表示法：等式约定与运算规则

8.1 f(n) = O(g(n)) 的本质是 f(n) ∈ O(g(n))

以大 O 符号为例：f(n) = O(g(n)) 的本质含义是 f(n) ∈ O(g(n))（集合的属于关系）。例如：

  • an2 + bn + c = O(n2)，即 an2 + bn + c ∈ O(n2)；
  • n = O(n2)，即 n ∈ O(n2)；
  • 2n2 + 3n + 1 = 2n2 + Θ(n)，表示 2n2 + 3n + 1 = 2n2 + f(n)，其中 f(n) 是某个属于集合 Θ(n) 的函数。

渐近记号的这种用法有助于略去一个等式中无关紧要的细节。

易错：渐近记号出现在等式左边时

含义是：无论等号左边渐近记号表示的匿名函数如何选择，总有办法选取等号右边的匿名函数使等式成立。

例：2n2 + Θ(n) = Θ(n2)，即对任意函数 f(n) ∈ Θ(n)，都存在函数 g(n) ∈ Θ(n2)，使得对所有的 n 有 2n2 + f(n) = g(n) 成立。

根据以上规则，可以得到一串关于渐进记号的等式：

2n2 + 3n + 1 = 2n2 + Θ(n) = Θ(n2)

8.2 运算规则

规则说明
O(f) + O(g) = O(max(f, g))两项相加取量级大的那项
O(f) + O(g) = O(f + g)也可以直接写成和的记号
O(f) · O(g) = O(f·g)相乘时量级相乘
若 g(N) = O(f(N))，则 O(f) + O(g) = O(f)被吸收：小的那一项直接丢掉
O(c·f(N)) = O(f(N))，其中 c 是正常数常数系数可以丢掉
f = O(f)自反性

9. 求解递归式：代换法

归并排序的分析需要求解一个递归式；求解递归式就像求解积分、微分方程一样，需要学会一些技巧。常用方法有三种：代换法、递归树、主方法。

代换法（Substitution Method）—— 最通用的方法

① 猜测解的形式；② 通过推导验证；③ 解出常数。

例：T(n) = 4T(n/2) + n，假设 T(1) = Θ(1)。先猜测 O(n3)（分别证明 O 和 Ω）：假设对所有 k < n 有 T(k) ≤ ck3，通过推导证明 T(n) ≤ cn3。

O(n3) 的完整推导：

T(n) = 4T(n/2) + n ≤ 4c(n/2)3 + n = (c/2)n3 + n = cn3 − ( (c/2)n3 − n ) ≤ cn3

这里 cn3 是"期望"，(c/2)n3 − n 是"余项"。只要余项 (c/2)n3 − n ≥ 0（例如 c ≥ 2 且 n ≥ 1），就有"期望 − 余项 ≤ 期望"，即 T(n) ≤ cn3。

初始条件的处理：必须保证推导在初始情况成立。当 n0 为适当常量时，对所有 n < n0 有 T(n) = Θ(1)；只要 c 选得足够大，对 1 ≤ n < n0 就有 Θ(1) ≤ cn3。注意这个界并不紧密。

9.1 猜一个更接近的上界 O(n2)：证明失败

要证 T(n) = O(n2)，假设对 k < n 有 T(k) ≤ ck2，代入：

T(n) = 4T(n/2) + n ≤ 4c(n/2)2 + n = cn2 + n = cn2 − (−n) ≤ cn2 ??

把它写成"期望 − 余项"，余项是 −n。要得到 T(n) ≤ cn2 必须余项 ≥ 0，但 没有任何 c > 0 能满足（−n < 0 对一切 n ≥ 1 成立）。所以这个证明是错的，不能据此得出 T(n) = O(n2)。

9.2 补救思想：加强推导的假设（减一个低阶项）

设对所有 k < n 有 T(k) ≤ c1k2 − c2k，则

T(n) = 4( c1(n/2)2 − c2(n/2) ) + n = c1n2 − 2c2n + n = c1n2 − c2n − ( c2n − n )

只要 c2 ≥ 1，就有 T(n) ≤ c1n2 − c2n ≤ c1n2

剩余一步：选择足够大的 c1 使初始条件成立。于是 T(n) = O(n2) 得证；再结合下界 T(n) ≥ n2，可得 T(n) = Θ(n2)。

代换法：T(n) = 4T(n/2) + n 猜 O(n²) 的失败与加强假设后的成功（8 步）

1  guess ← c·n²                                // ① 猜测解的形式：先猜 T(n) = O(n²)
2  假设对所有 k < n 有 T(k) ≤ c·k²            // 归纳假设：更小规模上猜测成立
3  T(n) ← 4·T(n/2) + n                         // 把猜测代入原递归式
4  T(n) ≤ 4c(n/2)² + n = c·n² + n            // 用归纳假设替换 T(n/2)
5  rem ← c·n² − T(n) = −n                   // 余项 = 期望 − 实际上界
6  if rem < 0 then return FAIL                  // 余项为负 ⇒ 没有 c>0 可行 ⇒ 证明失败
7  guess ← c₁·n² − c₂·n                   // ③ 加强假设：减一个低阶项
8  T(n) ≤ 4(c₁(n/2)² − c₂(n/2)) + n          // 把加强后的假设代入
9  T(n) ≤ c₁n² − c₂n − (c₂n − n)         // 整理成"期望 − 余项"的形式
10 if c₂ ≥ 1 then return SUCCESS             // 余项 c₂n − n ≥ 0 ⇒ 上界成立
11 取足够大的 c₁ 使初始条件成立                  // ② 解出常数：兼顾初始情况
12 return T(n) = O(n²)                       // 结论：紧界 O(n²)

C++

#include <cmath>                                  // 用到 pow、fabs 等数学函数
// 返回"期望 − 实际上界"的余项：≥0 表示猜测可行
double remainderWeak(double n, double c) {        // 弱假设 T(k) ≤ c·k² 的余项
    double upper = 4.0 * c * (n / 2) * (n / 2) + n;   // 用归纳假设得 T(n) 的上界 c·n²+n
    return c * n * n - upper;                     // 期望 c·n² 减去上界 ⇒ 余项 = −n
}                                                 // 结束 remainderWeak（弱假设余项）
bool weakGuessFails(double n) {                   // 检验弱假设是否真的失败
    for (double c = 0.1; c < 1e6; c *= 10) {       // 枚举任意大的正数 c，逐一试探
        if (remainderWeak(n, c) >= 0) return false;    // 只要有一个 c 可行就不算失败
    }                                             // 结束 c 枚举循环
    return true;                                  // 全部 c 都失败 ⇒ 弱假设被否定
}                                                 // 结束 weakGuessFails
bool remainderStrong(double n, double c1, double c2) {  // 强假设的余项是否非负
    double upper = 4.0 * (c1 * (n/2) * (n/2) - c2 * (n/2)) + n;  // 代入 T(k) ≤ c₁k² − c₂k
    return upper <= c1 * n * n - c2 * n;           // 等价于要求 c₂n − n ≥ 0
}                                                 // 结束 remainderStrong（强假设余项）
int main() {                                      // 主函数：打印两种假设的验证结果
    double n = 10.0;                              // 取一个规模 n = 10 做数值验证
    bool fail = weakGuessFails(n);                 // 弱假设：应输出失败
    bool ok = remainderStrong(n, 4.0, 1.0);        // 强假设：c₁=4、c₂=1 应输出成功
    return (fail && ok) ? 0 : 1;                  // 两者都符合预期则返回 0
}                                                 // 结束 main 函数（代换法验证演示）

10. 递归树法

递归树方法对算法递归执行的花费（时间）建模：把递归展开成一棵树，节点表示子问题的代价，逐层求和即得总代价。

  • 递归树方法可以用作代换法之前的猜想来源；
  • 递归树方法可能不是很可靠（例如需要仔细处理叶子层的边界），然而它有很重要的启发作用。

10.1 例一：T(n) = T(n/4) + T(n/2) + n2

注意本例的两个子问题规模不相等（n/4 和 n/2），因此不能用主方法，递归树是首选工具。

图 7  T(n) = T(n/4) + T(n/2) + n2 的递归树：每层代价是上层的 5/16 倍，构成公比小于 1 的几何级数

逐层求和的过程：n2 → (n/4)2 + (n/2)2 = (1/16 + 1/4)n2 = 5n2/16 → 25n2/256 → …，公比 5/16 < 1，故

和 = n2( 1 + 5/16 + (5/16)2 + (5/16)3 + … ) = n2 · 1/(1 − 5/16) = 16n2/11 = Θ(n2)

递归树 T(n) = T(n/4) + T(n/2) + n² 逐层生长（7 步）

10.2 例二：T(n) = 3T(n/4) + cn2

这次子问题规模相同，可以用主方法（a = 3、b = 4，nlogba = nlog43 ≈ n0.793，而 f(n) = cn2 更大，属于情况 3），但用递归树看得更清楚。逐层展开的费用是：

层次节点数该层总代价化简
第 0 层1cn2cn2
第 1 层33 · c(n/4)2(3/16)cn2
第 2 层3232 · c(n/42)2(3/16)2cn2
第 i 层3i3i · c(n/4i)2(3/16)icn2
叶子层3log4n = nlog43Θ(nlog43)Θ(n0.793)

共 log4n 层，于是

T(n) = ∑i=0log4n − 1 (3/16)i cn2 + Θ(nlog43)

因为 3/16 < 1，几何级数收敛到常数倍 cn2（无穷和 = cn2/(1 − 3/16) = 16cn2/13），而叶子层 Θ(n0.793) 是低阶项，故

T(n) = O(n2)  （对应主方法情况 3：根层代价 f(n) = cn2 主导）

10.3 例三：T(n) = T(n/3) + T(2n/3) + cn（主方法不适用）

PPT 另外给出一个例子：T(n) = T(n/3) + T(2n/3) + cn，并注明"该问题的子问题规模不一样"。此时 a = 2 但两个子问题规模不同（n/3 与 2n/3），不满足主方法"每个子问题规模都是 n/b"的前提。

用递归树分析：每一层的总代价都是 cn（同一层所有节点的规模之和恒为 n），而最长的递归路径沿着 2n/3 分支走，深度为 log3/2n，所以

T(n) = cn · log3/2n + O(n) = Θ(n lg n)  （补充结论，供参考）

10.4 递归树求和的实现骨架（伪代码 + C++）

伪代码

RECURSION-TREE-SUM(n)                  // 递归树法：求 T(n)=T(n/4)+T(n/2)+n² 的总代价
1  total ← n²                          // 第 0 层（根）的代价就是 n²
2  level ← n²                          // level 记录"当前这一层"的总代价
3  r ← 1/16 + 1/4 = 5/16                 // 每层的公比：(n/4)²+(n/2)² 相对 n² 的倍数
4  for i ← 1 to ∞ do                    // 逐层向下累加，直到层代价可忽略
5      level ← level × r                // 第 i 层代价 = 上一层代价 × 5/16
6      total ← total + level              // 把该层代价累加进总和
7      if level < ε·n² then break        // 层代价小于阈值就停止（公比 < 1 保证收敛）
8  return total = 16n²/11 = Θ(n²)        // 几何级数求和 ⇒ 得到紧界 Θ(n²)

C++

// 用几何级数累加估算递归树的总代价（n 用 double 表示规模）
double treeSum(double n, double eps) {           // eps 为停止阈值（相对 n² 的比例）
    const double r = 5.0 / 16.0;                 // 每层代价的公比 5/16 < 1
    double total = n * n;                        // 第 0 层代价 n² 计入总和
    double level = n * n;                        // 当前层代价，初值为根代价
    for (int i = 1; i < 10000; ++i) {            // 最多迭代 10000 层，防止死循环
        level *= r;                              // 进入下一层：代价乘以公比
        total += level;                          // 累加该层代价
        if (level < eps * n * n) break;          // 层代价足够小 ⇒ 收敛，提前结束
    }                                             // 结束逐层累加循环
    return total;                                // 返回值约为 1.4545·n²
}                                                 // 结束 treeSum（递归树求和）
int main() {                                     // 主函数：验证收敛结果
    double n = 100.0;                            // 取规模 n = 100 做数值实验
    double t = treeSum(n, 1e-9);                 // 阈值取 n² 的 1e-9
    return (t < 1.46 * n * n && t > 1.45 * n * n) ? 0 : 1;  // 结果应落在 1.45~1.46 倍 n² 之间
}                                                 // 结束 main 函数（递归树求和演示）

11. 主方法（Master Method）

主方法给出求解如下形式递归式的方法：

T(n) = aT(n/b) + f(n)， 其中 a ≥ 1、b > 1 是常数，f(n) 是渐近正的函数

它描述了这样一类算法的运行时间：把规模为 n 的问题划分为 a 个子问题，每个子问题的规模为 n/b；每个子问题的求解时间为 T(n/b)，划分与合并的时间为 f(n)。

比较基准

把 nlogba 作为基准 —— 它就是递归树叶子层的总代价量级：叶子数为 ah = alogbn = nlogba，每个叶子的代价是 T(1) = Θ(1)。三种情况本质上就是比较 f(n) 与 nlogba 的大小关系。

11.1 三种情况（条件与结论）

情况条件结论递归树权重分布
情况 1 f(n) = O(nlogba − ε)，常量 ε > 0
f(n) 比多项式 nlogba 增长得慢（慢 nε 倍）		 T(n) = Θ(nlogba) 加权从根到叶子几何级数增长，叶子在总权重中仅占常量部分
情况 2 f(n) = Θ(nlogba)
即每层加权基本相同（f(n) = Θ(nlogba lgkn)，k = 0）		 T(n) = Θ(nlogba lg n)
= Θ(f(n) lg n)		 每层的加权基本相同，共 logbn 层
情况 3 f(n) = Ω(nlogba + ε)，常量 ε > 0
f(n) 比 nlogba 增长得快（快 nε 倍）
并且 f(n) 满足规定条件 a·f(n/b) ≤ c·f(n)，常量 c < 1		 T(n) = Θ(f(n)) 权重从根到叶子几何级数递减，根在整个权重中仅仅是常量部分

情况 3 的两个条件缺一不可

光有 f(n) = Ω(nlogba + ε) 还不够，还必须验证正则条件（regularity condition）a·f(n/b) ≤ c·f(n)（常量 c < 1）。它的含义是"每往下一层，加权至少缩小一个固定比例"，这样才能保证根层代价在总代价中占常数比例。

11.3 四个必会例题

递归式nlogba 与 f(n)判定结论
T(n) = 4T(n/2) + n a = 4、b = 2 ⇒ nlogba = n2；f(n) = n 情况 1：f(n) = O(n2−ε)，取 ε = 1 T(n) = Θ(n2)
T(n) = 4T(n/2) + n2 nlogba = n2；f(n) = n2 情况 2：f(n) = Θ(n2lg0n)，即 k = 0 T(n) = Θ(n2 lg n)
T(n) = 4T(n/2) + n3 nlogba = n2；f(n) = n3 情况 3：f(n) = Ω(n2+ε)，取 ε = 1；正则条件 4(cn/2)3 ≤ cn3 取 c = 1/2 成立 T(n) = Θ(n3)
T(n) = 4T(n/2) + n2/lg n nlogba = n2；f(n) = n2/lg n 三种情况都不满足 这时主方法不适用

最后一个例子的原因值得单独记：f(n) = n2/lg n 虽然比 n2 小，但只小了 lg n 倍，不是多项式地小 —— 找不到任何 ε > 0 使 f(n) = O(n2−ε)，所以情况 1 不成立；f(n) ≠ Θ(n2)，情况 2 不成立；f(n) 也不比 n2 大，情况 3 不成立。这时只能改用递归树或代换法。（补充：该递归式的解为 T(n) = Θ(n2 lg lg n)，PPT 未给出，仅供参考。）

11.4 主方法的判定骨架（伪代码 + C++）

伪代码

MASTER-METHOD(a, b, f, n)                 // 主方法：判定 T(n)=aT(n/b)+f(n) 属于哪种情况
1  if a < 1 or b ≤ 1 then return 不适用        // 前提：a ≥ 1、b > 1 且 f 渐近正
2  base ← nlog_b a                        // 比较基准 = 递归树叶子层的总代价量级
3  if f = O(n^(log_b a − ε)) (ε > 0) then   // 情况 1：f 比基准多项式地慢
4      return Θ(nlog_b a)                  // 叶子层主导
5  if f = Θ(nlog_b a) then                 // 情况 2：f 与基准同阶
6      return Θ(nlog_b a · lg n)             // 共 log_b n 层，每层同阶
7  if f = Ω(n^(log_b a + ε)) (ε > 0) then    // 情况 3：f 比基准多项式地快
8      if a·f(n/b) ≤ c·f(n) (c < 1) then          // 还必须满足正则条件
9          return Θ(f(n))                     // 根层主导
10 return 不适用                                  // 三种情况都不满足 ⇒ 换递归树 / 代换法

C++

#include <cmath>                                // 需要 pow、log 计算基准 n^(log_b a)
#include <string>                               // 返回中文结论用 std::string
// 判断 f(n) 相对基准 n^(log_b a) 的关系（用 double 近似 ε 比较）
std::string masterMethod(double a, double b, double n,   // a 为子问题个数，b 为每层规模缩小因子
                         double (*f)(double), double (*fDivB)(double)) {  // fDivB 即 f(n/b)
    if (a < 1.0 || b <= 1.0) return "不适用：要求 a ≥ 1 且 b > 1";        // 前提检查
    double base = std::pow(n, std::log(a) / std::log(b));  // 基准 n^(log_b a)
    double fv = f(n);                                    // 当前 f(n) 的数值
    if (fv * std::pow(n, 0.5) <= base)                   // 取 ε = 0.5 试探情况 1 的条件
        return "情况1：T(n) = Θ(n^(log_b a))";        // f 多项式地小于基准
    if (fv <= 2.0 * base && fv >= 0.5 * base)           // 常数因子范围内相等即同阶
        return "情况2：T(n) = Θ(n^(log_b a) lg n)";  // 情况 2：每层同阶
    if (fv >= base * std::pow(n, 0.5)) {                 // 取 ε = 0.5 试探情况 3 的条件
        double c = a * fDivB(n) / fv;                    // 正则条件中的比值 a·f(n/b) / f(n)
        if (c < 1.0) return "情况3：T(n) = Θ(f(n))"; // 比值小于 1 才能用情况 3
    }                                             // 结束情况 3 的条件判断块
    return "主方法不适用：改用递归树或代换法";              // 落到这里说明三种情况都不满足
}                                                 // 结束 masterMethod 函数

12. 循环不变式与算法正确性证明

循环不变式 (loop invariant) 方法：先确定算法的循环不变式，然后检查此循环不变式在算法执行期间是否满足以下三个条件：

三个条件

① 初始状态 (Initialization)：循环前循环不变式为真。
② 保持状态 (Maintenance)：如果本次循环前循环不变式为真，则本次循环后依然为真。
③ 终止状态 (Termination)：退出循环时，循环不变式为真。

前两个性质成立时，就能保障循环不变式在循环的每一轮迭代开始前都是正确的 —— 这与数学归纳法类似：初始状态对应归纳基础，保持状态对应归纳步骤；而第三条把不变式"翻译"回算法的正确性结论。

图 9  插入排序的循环不变式：子数组 A[1..j−1] 始终有序，Temp 槽存放本轮待插入的关键字

12.1 插入排序：伪代码 + C++（逐行注释）

伪代码（PPT 写法）

INSERTION-SORT(A)                       // 对数组 A[1..n] 做直接插入排序（升序）
1  for j = 2 to A.length                // j 从第 2 个元素开始，逐个把 A[j] 插入前面的有序区
2      key = A[j]                        // 取出本轮待插入的关键字，放进 Temp 槽
3      i = j - 1                         // i 指向已排序子数组 A[1..j-1] 的最后一个元素
4      while i > 0 and A[i] > key         // 从右往左找插入位置：凡比 key 大的都要右移
5          A[i+1] = A[i]                 // 把 A[i] 后移到 A[i+1]，为 key 腾出空位
6          i = i - 1                     // i 继续左移，继续与 key 比较
7      A[i+1] = key                      // 空出来的位置就是 key 的归宿，插入之

C++

void insertionSort(int A[], int n) {          // 直接插入排序：把 A[0..n-1] 升序排列
    for (int j = 1; j < n; ++j) {             // 对应伪代码 for j = 2 to A.length（C++ 下标从 0 起）
        int key = A[j];                       // 取出待插入的关键字 A[j]
        int i = j - 1;                        // i 指向已排序区间 A[0..j-2] 的末尾
        while (i >= 0 && A[i] > key) {       // 从右往左扫描，找第一个不大于 key 的位置
            A[i + 1] = A[i];                  // 把比 key 大的元素整体后移一位
            --i;                              // 继续向左比较
        }                                         // 结束 while：插入位置已找到
        A[i + 1] = key;                       // 把 key 放到正确位置，有序区扩充为 A[0..j-1]
    }                                         // 每轮结束后不变式"A[0..j-1] 有序"都成立
}                                             // 结束 insertionSort 函数

12.2 插入排序的正确性证明（完整三步）

循环不变式：子数组 A[1..j−1] 始终为排好序的状态。

① 初始状态 (Initialization)：
∵ 循环开始前 j = 2；
∴ 进入循环前子数组 A[1..j−1] = A[1..1] 只有一个元素，此时子数组为排好序的状态。不变式成立。

② 保持状态 (Maintenance)：
∵ while 循环前 i = j−1，若子数组 A[1..i] = A[1..j−1] 为真（即前 j−1 个元素有序）；循环开始时，插入排序的过程是依次后移 A[j−1]、A[j−2]、… 并把新的关键字 key = A[j] 插入到合适的位置，此时子数组 A[1..j−1] 扩充为 A[1..j] 且为排好序的状态；
∴ j++ 后循环不变式 A[1..j−1]（此时是 A[1..j]）为真。

③ 终止状态 (Termination)：退出循环时，
∵ j = n+1，此时子数组 A[1..j−1] = A[1..n] 包含所有元素且为排好序的状态；
∴ 循环不变式为真，即整个数组已经有序 —— 算法正确。

答题模板

写正确性证明时固定用三段：初始 → 保持 → 终止。前两段说明"不变式在每轮开始前都成立"（归纳），第三段把不变式与"退出条件"合起来推出最终结论。注意③不能省 —— 前两条只保证"过程中一直对"，只有终止条件才能说明"结束时算法目标达成"。

考前速记清单

  1. 渐进复杂性：略去低阶项后的主项；T(N)=3N2+4NlogN+7 → T′(N)=3N2。
  2. 五个记号：Θ（∃c1,c2，夹住，紧致界）、O（∃c，上界）、Ω（∃c，下界）、o（∀c，非紧上界）、ω（∀c，非紧下界）。
  3. 定理 1.1：Θ ⇔ O 且 Ω；Θ 强于 O（Θ(g) ⊆ O(g)）。
  4. 二次多项式：an2+bn+c = Θ(n2)，取 c1=a/4、c2=7a/4、n0=2max(|b|/a, √(|c|/a))。
  5. 极限比较：0 → o；有限正常数 → Θ；∞ → ω。
  6. 四条性质：传递性（小 o 那条全是小 o）、自反性（非紧界无自反性）、对称性（Θ）、转置对称性（O⇔Ω、o⇔ω）→ 类比实数比较。
  7. 代换法：猜 → 验 → 定常数；余项必须 ≥ 0；猜 n2 会失败（余项 −n），加强假设 c1k2−c2k 后成功（c2 ≥ 1）。
  8. 递归树：逐层求和；T(n)=T(n/4)+T(n/2)+n2 公比 5/16 < 1 ⇒ Θ(n2)；T(n)=3T(n/4)+cn2 每层 (3/16)icn2，3/16 < 1 ⇒ O(n2)。
  9. 主方法：基准 nlogba；情况 1 Θ(nlogba)、情况 2 Θ(nlogbalg n)、情况 3 Θ(f(n))（需 a·f(n/b) ≤ c·f(n)，c < 1）。
  10. 主方法不适用：T(n)=4T(n/2)+n2/lg n（非多项式地小）、T(n)=T(n/3)+T(2n/3)+cn（子问题规模不同）。
  11. 循环不变式三条件：初始 / 保持 / 终止；插入排序的不变式是 A[1..j−1] 始终有序，终止时 j = n+1 得 A[1..n] 有序。

本节自测（课件配套测验）

本题取自课程配套测验（算法分析基础部分），考的是「渐进复杂性 = 略去低阶项后的主项」这一核心概念。

一、单项选择题

1. T(N) = 3N² + 4N log N + 7 的渐进主项是什么？算法分析基础 · 原卷 4

  • A. 4N log N
  • B. 3N²
  • C. 7
  • D. N

答案：B　渐进复杂性 T′(N) 是 T(N) 略去低阶项后留下的主项：当 N→∞ 时 (T(N)−T′(N))/T(N) → 0。这里三项的量级分别是 N²（最高阶）、N log N（介于 N 与 N² 之间）、7（常数，最低阶），所以主项是 3N²，即 T(N)=Θ(N²)。

易错：主项只砍「阶」，不砍系数 —— 所以是 3N² 而不是 N²；等到用 Θ 记号时才丢掉系数。
