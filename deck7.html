    动态规划：表格法、最优子结构与五个经典问题

    本讲对应课程 PPT 第 15 章（97 页，全书内容最多的一讲）。核心是一条主线：动态规划 = 分治思想 + 解决冗余，靠表格把重复子问题的解存起来，用逆拓扑序把表填满。围绕这条主线依次解决五个问题：钢条切割（r4 = 10）、矩阵链乘法（m(1,6) = 15125）、最长公共子序列（c[7,6] = 4，LCS 为 BCBA）、装配线调度（f* = 38）、最优二叉搜索树（e(1,5) = 2.75）。五个问题的递归式、算例表格全部按 PPT 原图还原，并对每一格做了独立复算。

    1. 动态规划的基本思想：一张表解决重复子问题

    1.1 programming 是"表格法"，不是"写程序"

    动态规划（Dynamic Programming, DP）这个名字里的 programming，指的是一种表格法（tabular method）—— 把子问题的答案填进一张表里，而不是"编写计算机程序"。这一点 PPT 第 3 页专门点出，考试里也常作为概念题出现。

    基本思想（PPT 第 3 页原文）

    • 和分治法类似，都是通过组合子问题的解而得到整个问题的解；
    • 所不同的是，动态规划法适用于子问题重叠的情况 —— 也就是不同的子问题具有公共的子问题；
    • 子问题的求解递归进行，将其划分为更小的子子问题；
    • 通常用来求解最优化问题（max / min）。

    为什么"子问题重叠"是关键？因为一旦不同的子问题共用同一个更小的子问题，朴素的递归就会把同一个子问题算很多遍。看一个最熟悉的例子：

    FIB(n)                          // 朴素递归求斐波那契第 n 项
1  if n ≤ 1                      // 边界：F(0) = 0、F(1) = 1
2      return n                 // 直接返回
3  return FIB(n−1) + FIB(n−2)    // 递归：同一子问题被反复展开

    计算 F(5) 时 F(3) 会被算 2 次、F(2) 会被算 3 次、F(1) 会被算 5 次，递归树节点数随 n 指数增长；而不同子问题其实只有 n+1 个。把这 n+1 个答案存进一张表，时间立刻从指数降到 O(n) —— 这就是动态规划要干的事（斐波那契的 DP 写法见 第 8 节）。

    1.2 实质：分治思想 + 解决冗余

    动态规划的实质（PPT 第 4 页）

    分治：将问题实例分解为更小的、相似的子问题。
    解决冗余：存储子问题的解而避免计算重复的子问题，以解决最优化问题的算法策略。

    • 所解决问题的特征：子问题呈现大量的重复；
    • 动态规划法的关键：对于重复出现的子问题，只在第一次遇到时加以求解，并把答案保存起来；以后再遇到时直接引用，不必重新求解；
    • 代价：付出额外的内存空间来节省时间（时空权衡 time-space tradeoff）。在钢条切割这样的例子里，"时间上的节省是巨大的"—— 从 2n−1 降到 n2。

    1.4 两种等价的实现：带备忘的自顶向下 vs 自底向上

    PPT 第 10~11 页把"如何安排子问题的求解顺序"拆成两条路，并强调二者等价：

    对比项带备忘的自顶向下（记忆化 memoization）自底向上（bottom-up）
    写法仍按自然的递归形式编写，只是过程会保存每个子问题的解（数组或散列表）；需要时先查表，有就返回，没有才计算恰当定义子问题"规模"，使任何子问题只依赖"更小的"子问题；按规模由小至大顺序求解
    求解顺序由递归调用自然决定（"用到才算"）逆拓扑序（反序的拓扑序）：对于任何子问题，直至它依赖的所有子问题都已求解完成，才会求解它
    优点只有用到的子问题才被计算没有递归调用的开销，也不用查表判断"算过没有"
    缺点需要保存全部已算表项，递归栈有开销即使某些子问题用不到，也必须全部算一遍
    什么时候选它很多子问题不需要计算时更好 —— 只有用到的项被计算所有子问题都必须计算至少一次时更好 —— 减少了递归和维护表的负担

    "逆拓扑序"这个词来自子问题图（subproblem graph）：把每个子问题看成一个顶点，若求解子问题 x 时需要子问题 y 的解，就画一条有向边 (x, y)。下图就是 PPT 第 12 页的 n = 4 钢条切割子问题图，它其实是第 9 页递归调用树的"简化版" —— 树中标号相同的结点收缩成单一顶点。

    图 1  n = 4 钢条切割的子问题图（PPT 第 12 页原图）—— 10 条边对应 10 次"用到更小子问题"

    易错：DP 不是"递归 + 一张表"就算完

    如果子问题根本不重叠（分治的典型情形，如归并排序的两个半区），存表只会白白多花 Θ(n) 甚至 Θ(n2) 的空间而一点时间也省不下。判断能不能用 DP，第一步永远是问：递归展开后有没有同一个子问题被算多次？

    本节考点

    ① programming = 表格法；② 与分治的相同点是"组合子问题的解"，不同点是"适用于子问题重叠"；③ 实质 = 分治 + 解决冗余；④ 四个设计步骤（刻画结构 → 递归定义值 → 计算值 → 构造解）；⑤ 两种实现（备忘 / 自底向上）等价，自底向上按逆拓扑序填表；⑥ 时空权衡：用内存换时间。

    2. 动态规划原理：两个要素与适用性

    2.1 两个要素：最优子结构 + 重叠子问题

    PPT 第 39 页：动态规划算法的有效性依赖于两个重要性质，这是采用动态规划算法的基本要素。

    要素 1：最优子结构（optimal substructure）—— "动态规划标志 #1"

    当问题的最优解包含其子问题的最优解时，称该问题具有最优子结构性质。它提供了"可以用动态规划算法求解"的线索。

    例：矩阵连乘问题，把 A1A2…An 在第 k 个位置断开，分解为两个子问题（加括号方式求解）；于是可以采用自底向上的方式求解，并且可以在相对较小的子问题空间中考虑问题。

    要素 2：重叠子问题（overlapping subproblems）—— "动态规划标志 #2"

    子问题的重叠性质：每次产生的子问题并不总是新问题，有些子问题被反复计算。因此采用动态规划法只计算每个子问题一次，并放到表中，需要时再查表即可。

    例：矩阵连乘计算问题中，子问题只有 Θ(n2) 数量级（不同的 (i, j) 对共 n(n+1)/2 个），而朴素递归的调用次数是指数的。

    这两个要素在证明题里的用法不同：最优子结构用反证法 / 剪贴法（cut & paste）证明；重叠子问题用"数一数不同子问题的个数"来论证。两件事都成立，才能把指数时间压成多项式时间。

    2.2 DP 与分治的对比

    PPT 第 35 页把两者摆在一起对照，结论只有一句话：两者都是合并子问题的解来解决问题，区别在于子问题是否独立。

    对比项分而治之（divide & conquer）动态规划（DP）
    子问题关系把问题划分为独立的子问题子问题重叠（不同子问题有公共的子问题）
    求解方式递归地解决子问题，然后把它们的解组合得到原问题的解每个子问题仅仅解决一次，结果存表，以后查表
    效率隐患如果相同的子问题出现多于一次，算法效率不高（指数级重复）适合子问题重叠的情况，重复被"查表"消掉
    典型例子归并排序、二分查找、Hanoi 塔钢条切割、矩阵链、LCS、装配线、OBST
    共同点都需要最优子结构（或可分性）：原问题的解由子问题的解组合而成

    PPT 第 36 页还给了一份"通用方法 + 开发 DP"的清单，可以当成四步的另一种说法：

    • 典型应用为最优化问题；
    • 通用方法：计算所有子问题的解 → 利用小的子问题来解决大的子问题 → 子问题的计算基于以前计算的更小的子问题的结果 → 将子问题的结果存储在表中，不再重新计算；
    • 开发 DP：研究最优方案的结构 → 递归定义最优方案的值 → 从底向上计算最优方案的值 → 从计算的结果创建最优方案（如果仅仅需要最优值，此步可以忽略）。

    2.3 什么时候使用动态规划（DP 的适用性讨论）

    PPT 第 37 页的说法很干脆：DP 通过存储部分结果来进行高效的递归计算，所以它仅仅在"部分结果的数目比较小"的时候才好用。这句话是判断适用性的总纲。

    情形子问题 / 部分结果的规模能否用 DP
    无望：n 个元素集合的排列组合n!不能 —— 表根本装不下
    无望：n 个元素的全部子集2n不能 —— 指数个表项
    有希望：n 个字符的字符串的连续子串Θ(n2)可以（如 LCS 的 mn 个子问题）
    有希望：二叉搜索树的可能子树Θ(n2)可以（OBST 的 e[i,j] 共 n(n+1)/2 项）

    记忆：DP 的最佳应用是"线性有序、但却不能排序"的对象

    典型清单（PPT 第 37 页）：矩阵链（矩阵的顺序不能重排）、字符串中的字符（字符顺序不能动）、多边形边界周围的点、圆上的点、搜索树中叶子从左到右的顺序。

    共同特征：对象从左到右有序，但这个顺序不能通过排序改变 —— 于是子问题天然落在"区间 [i, j]"上，表也就是二维区间表。

    2.4 两种 DP 方法的取舍（PPT 第 38 页）

    从下向上迭代方法从上到下递归方法（记忆）
    起点从递归的分而治之算法开始保持原始算法从上到下的方法
    关键动作找到子问题之间的依赖关系（计算子问题需要什么样的解），按照正确的顺序解决子问题将子问题的解保存在表中（可能需要很多存储空间），只有当子问题的解在表中没有的时候才进行递归
    更优的场合如果所有的子问题都必须计算至少一次如果很多子问题不需要计算
    原因减少了递归和维护表的负担只有用到的项被计算

    易错：把"重叠子问题"和"子问题无关"混为一谈

    这两个词描述的是相反的两件事，而且都和"能否用 DP"直接相关：重叠子问题是"同一个子问题被多个父问题共用"，这是 DP 的机会（可以省时间）；子问题无关是"同一个原问题的两个子问题的解互不影响、不争用资源"，这是最优子结构能成立的前提。最短路径的子问题相互不共享顶点（子问题无关）→ 有最优子结构；最长路径的子问题会争用顶点（子问题相关）→ 没有最优子结构。详见 第 5 节的延伸。

    本节考点

    ① 两个要素：最优子结构 + 重叠子问题（"标志 #1 / #2"）；② DP 与分治：相同 = 组合子问题的解，不同 = 子问题是否重叠；③ 适用性：无望（n!、2n）vs 有希望（连续子串、子树）；④ 最佳应用 = 线性有序但不能排序的对象；⑤ 两种方法的选择口诀：子问题全要算 → 自底向上；只需一部分 → 自顶向下。

    3. 习题 1：钢条切割（rod cutting）

    3.1 问题描述

    Serling 公司购买长钢条，将其切割为短钢条出售。切割工序本身没有成本支出。公司管理层希望知道最佳的切割方案。假定我们知道 Serling 公司出售一段长为 i 英寸的钢条的价格为 pi（i = 1, 2, …，单位为美元），钢条的长度均为整英寸。

    钢条切割问题

    给定一段长度为 n 英寸的钢条和一个价格表 pi（i = 1, 2, … n），求切割钢条方案，使得销售收益 rn 最大。

    注意：如果长度为 n 英寸的钢条的价格 pn 足够大，最优解可能就是完全不需要切割。

    PPT 图 15-1 给出的价格表样例（已逐格核对 PPT 第 5 页的图片 image5.png）：

    长度 i12345678910
    价格 pi1589101717202430

    3.2 切割方案举例：n = 4 的 8 种方案

    长度为 n 英寸的钢条共有 2n−1 种不同的切割方案 —— 因为在距离钢条左端 i（i = 1, 2, … n−1）英寸处，总是可以选择切割或不切割。所以 n = 4 时有 23 = 8 种方案（PPT 第 6 页的图，已核对 image6.png）：

    方案切割收益计算总收益
    (a)4（不切）p49
    (b)1 + 3p1 + p3 = 1 + 89
    (c)2 + 2p2 + p2 = 5 + 510
    (d)3 + 1p3 + p1 = 8 + 19
    (e)1 + 1 + 21 + 1 + 57
    (f)1 + 2 + 11 + 5 + 17
    (g)2 + 1 + 15 + 1 + 17
    (h)1 + 1 + 1 + 11 + 1 + 1 + 14

    最优方案是 2 + 2，收益 r4 = p2 + p2 = 5 + 5 = 10。注意方案 (c) 的收益比方案 (a) 的 p4 = 9 更大 —— 切反而比不切更赚钱。

    图 2  n = 4 的八种切割方案与收益（PPT 第 6 页原图）：最优方案 2 + 2 收益 10

    3.3 步骤一：刻画最优解的结构（最优子结构）

    PPT 第 7 页的推理是这样的：如果一个最优解将钢条切割为 k 段（对某个 1 ≤ k ≤ n），那么最优切割方案

    n = i1 + i2 + … + ik

    将钢条切割为长度分别为 i1, i2, …, ik 的小段，得到最大收益

    rn = pi1 + pi2 + … + pik

    最优子结构（PPT 第 7 页）

    更一般地，对于 rn（n ≥ 1），我们可以用更短的钢条的最优切割收益来描述它：

    rn = max( pn, r1 + rn−1, r2 + rn−2, …, rn−1 + r1 )

    第一个参数 pn 对应不切割；其余每个参数对应"切下第一段长度为 i、剩下长度 n−i 再取最优"的方案。等价的标准写法是：

    rn = max1 ≤ i ≤ n ( pi + rn−i )   ，   r0 = 0

    （PPT 第 8 页给出了这个"只含一个 r"的形式 rn = max1≤i≤n(pi + rn−i)，已核对图片 image9.png。）

    为什么这是最优子结构？用剪贴法（cut & paste）：设最优方案把钢条切成长度 i1, i2, …, ik 的段，总收益 pi1 + … + pik。若剩下的 n − i1 英寸存在收益更高的方案，把它粘上去就得到比"最优"更高的收益，矛盾。

    注意一个细节：rn = max(pi + rn−i) 里的 rn−i 本身就允许继续切，所以第一段切 i 之后右边那一部分的最优方案已经"递归地"包含了所有可能的切法 —— 不需要再讨论右边怎么切。这正是 DP 与"枚举 2n−1 种方案"的区别。

    3.4 步骤二：递归地定义最优解的值（朴素递归）

    PPT 第 8 页给出的递归过程 CUT-ROD(p, n)（p 价格数组、n 钢条长度、q 最大收益）：

    伪代码（PPT 第 8 页原图）

    CUT-ROD(p, n)                        // p 为价格数组，n 为钢条长度
1  if n == 0                         // 边界：长度为 0 的钢条
2      return 0                     // 收益为 0
3  q = −∞                            // q 保存当前找到的最大收益
4  for i = 1 to n                    // 枚举第一段切下的长度 i
5      q = max(q, p[i] + CUT-ROD(p, n − i))   // 首段收益 + 剩余部分递归
6  return q                          // 返回最大收益

    C++

    int cutRod(int p[], int n) {                  // p[1..n] 为价格表，n 为钢条长度
    if (n == 0) { return 0; }                 // 边界：长度为 0 时不产生收益
    int q = -1000000000;                      // 用很小的数表示"负无穷"
    for (int i = 1; i <= n; ++i) {            // 枚举第一段切下的长度 i
        int v = p[i] + cutRod(p, n - i);      // 首段 p[i] 加上剩余 n-i 的最优收益
        if (v > q) { q = v; }                 // 更大就更新最大收益
    }                                         // 结束枚举
    return q;                                 // 返回长度 n 的最大收益
}                                             // 结束 cutRod 函数

    这个递归程序的运行时间随 n 指数增长：每当 n 增大 1，程序运行时间差不多就会增加 1 倍。

    3.5 效率分析：递归树与重叠子问题

    PPT 第 9 页给出 n = 4 时的递归调用树（已核对 image11.png）：根结点标号 4，它的 4 个孩子分别是 3、2、1、0；标号 3 的结点又有 3 个孩子 2、1、0 …… 每个结点的标号就是对应子问题的规模，从父结点 s 到子结点 t 的边表示"从钢条左端切下长度为 s − t 的一段"。

    • 从根结点到叶结点的一条路径 = 长度 n 的钢条的 2n−1 种切割方案之一；
    • 这棵递归调用树共有 2n 个结点，其中有 2n−1 个叶结点；n = 4 时是 16 个结点、8 个叶结点；
    • 所以朴素递归的调用次数 T(n) = 2n = Θ(2n) —— 指数时间。

    罪魁祸首是"反复求解相同的子问题"：树中标号相同的结点被展开了一次又一次（标号 2 的结点出现 3 次、标号 1 的 5 次、标号 0 的 8 次）。而不同子问题只有 n+1 个（规模 0, 1, …, n）。把 5 个答案存进表，就得到下一小节的 Θ(n2) 算法。

    3.6 步骤三：计算最优解的值（两种实现）

    基本思路：仔细安排求解顺序，对每个子问题只求解一次，并将结果保存下来；如果随后再次需要此子问题的解，只需查找保存的结果。常用的算法设计思想：付出额外的内存空间来节省时间（时空权衡）。

    const int NEG = -1000000000;                   // 用很小的整数表示"负无穷"
int memo[11];                                  // 备忘数组，memo[i] 存长度 i 的最优收益

int memoizedCutRodAux(int p[], int n) {        // 递归辅助过程：求解长度 n
    if (memo[n] >= 0) { return memo[n]; }      // 查表命中就直接返回，避免重复计算
    int q;                                     // q 保存本规模的最优收益

    else {                                     // 长度大于 0 时枚举第一段

            if (v > q) { q = v; }              // 更新最大值
        }                                      // 结束枚举
    }                                          // 结束 else 分支
    memo[n] = q;                               // 结果写回表中
    return q;                                  // 返回最优收益
}                                              // 结束 memoizedCutRodAux

int memoizedCutRod(int p[], int n) {           // 带备忘的自顶向下驱动

    return memoizedCutRodAux(p, n);            // 从规模 n 开始递归
}                                              // 结束 memoizedCutRod

    (2) 自底向上法

    PPT 第 15 页的 BOTTOM-UP-CUT-ROD（已核对 image16.png）—— 按 j = 1, 2, …, n 的规模递增顺序（逆拓扑序）填表：

    伪代码（PPT 第 15 页原图）

    BOTTOM-UP-CUT-ROD(p, n)              // 自底向上求解
1  let r[0..n] be a new array         // 新建收益数组 r
2  r[0] = 0                           // 边界：长度 0 的收益为 0
3  for j = 1 to n                     // 按长度从小到大求解每个子问题
4      q = −∞                          // 当前长度 j 的最优收益
5      for i = 1 to j                 // 枚举第一段长度 i
6          q = max(q, p[i] + r[j−i])  // 注意：这里查表 r[j−i]，不再递归
7      r[j] = q                       // 保存长度 j 的最优收益
8  return r[n]                        // 返回长度 n 的最优收益

    C++

    int bottomUpCutRod(int p[], int n, int r[], int s[]) {   // r 存收益，s 存首段长度
    r[0] = 0;                                  // 边界：长度 0 的收益为 0
    for (int j = 1; j <= n; ++j) {             // 按长度 1..n 递增求解（逆拓扑序）
        int q = NEG;                           // 当前长度 j 的最优收益
        for (int i = 1; i <= j; ++i) {         // 枚举第一段的长度 i
            int v = p[i] + r[j - i];           // 首段收益 + 剩余部分"查表"
            if (v > q) { q = v; s[j] = i; }    // 更优就更新收益并记下首段长度
        }                                      // 结束枚举
        r[j] = q;                              // 保存长度 j 的最优收益
    }                                          // 结束长度循环
    return r[n];                               // 返回长度 n 的最优收益
}                                              // 结束 bottomUpCutRod

    复杂度：内层循环对每个 j 跑 j 次，总工作量 1 + 2 + … + n = Θ(n2)；空间 Θ(n)。从 Θ(2n) 到 Θ(n2)，这是"存表"带来的全部收益。

    4. 习题 2：矩阵链乘法（matrix-chain multiplication）

    4.1 问题描述

    给定 n 个矩阵 {A1, A2, …, An}，其中 Ai 与 Ai+1 是可乘的（i = 1, …, n−1），希望计算这 n 个矩阵的连乘积 A1A2…An。

    • Ai 与 Ai+1 可乘的条件：col(Ai) = row(Ai+1)；
    • 由于矩阵乘法满足结合律，因此任何加括号的方法都会得到相同的计算结果；
    • "完全括号化"（fully parenthesized）：它是单一矩阵，或者是两个完全括号化的矩阵乘积链的积；
    • 设矩阵 Ai 的规模为 pi−1 × pi，求完全括号化方案，使得计算乘积所需标量乘法次数最少。

    4.2 问题分析：两个矩阵相乘的代价

    两个矩阵相乘的次数：若 A 是 p × q、B 是 q × r，则 C = AB 是 p × r，共需 p · q · r 次标量乘法。

    PPT 第 21 页的经典例子：10×100、100×5、5×50

    方案一（先算前两个）：10·100·5 + 10·5·50 = 5000 + 2500 = 7500

    方案二（先算后两个）：10·100·50 + 100·5·50 = 50000 + 25000 = 75000

    同样的三个矩阵、同样的结果，只因为加括号的顺序不同，乘法次数相差 10 倍。这就是"要找最优完全括号化方案"的原因。

    若用直接的递归方法枚举所有完全括号化方案（PPT 第 22 页），方案数是指数级的：n−1 个断点的括号化方案数就是 Catalan 数 C(n−1)，其量级为 Ω(4n/n3/2)（此量级为补充说明，PPT 只说"直接的递归方法"）。因此必须用 DP。

    矩阵A1A2A3A4A5A6
    规模30×3535×1515×55×1010×2020×25

    即维度序列 P = (30, 35, 15, 5, 10, 20, 25)（p0 … p6，n = 6）。本节的 m 表、s 表都按这个算例（PPT 第 26、29 页，已核对 image23.png 的图 15-5）。

    4.3 步骤一：分析最优解的结构（反证法）

    将 A1A2…An 记为 A1..n，设在第 k 个位置上断开（1 ≤ k ≤ n−1），即对应计算 ((A1…Ak)(Ak+1…An))。计算量包括三部分：

    1. 计算 (A1…Ak) 的代价；
    2. 计算 (Ak+1…An) 的代价；
    3. 把这两个结果相乘的代价 p0·pk·pn。

    关键特征（PPT 第 23 页）

    计算 A1..n 的一个最优次序所包含的 A1..k 次序也是最优的。由此可知，矩阵链乘积的计算次序问题的最优解包含着其子问题的最优解 —— 称这种性质为最优子结构性质，这是可用动态规划算法的基本要素。

    反证法证明：若 A1..k 存在代价更小的括号化方案，把它替换进原方案，总代价会变小，与"原方案最优"矛盾；右侧 Ak+1..n 同理。∎

    4.4 步骤二：建立递归关系

    假设计算 Ai..j 所需要的最少标量乘法次数为 m(i, j)，则原问题的最优值为 m(1, n)。

    • 当 i = j 时，无需计算，m(i, j) = m(i, i) = 0；
    • 当 i < j 时，可用最优子结构性质来计算 m(i, j)：若在 k 处断开（i ≤ k < j），则 m(i, j) = m(i, k) + m(k+1, j) + pi−1pkpj；
    • 由于不知 k 的位置，需要在 j − i 个位置上选择使得 m(i, j) 最小的 k。

    m(i, j) = 0   (i = j)；   m(i, j) = mini ≤ k < j { m(i, k) + m(k+1, j) + pi−1 pk pj }   (i < j)

    若将 m(i, j) 对应的 k 值记录在 s(i, j) 中，则相应的最优解便可构造出来。

    4.5 步骤三：计算最优解（自底向上）

    不同子问题的个数是 O(n2)（i ≤ j 的区间共 n(n+1)/2 个），因此许多计算是重复的。为此采用自底向上的方法计算，计算过程中保存已经计算过的子问题的答案，以便后面更高层的计算直接引用。

    计算顺序（PPT 第 27~28 页，已核对 image23.png 的菱形图）—— 按矩阵链长度 L 递增：

    1. 先计算出 m(i, i) = 0，i = 1, 2, …, n（链长 1）；
    2. 计算 m(i, i+1)，i = 1, 2, …, n−1（矩阵链长度为 2）；
    3. 计算 m(i, i+2)，i = 1, 2, …, n−2（矩阵链长度为 3）；
    4. …… 依此类推。在计算 m(i, j) 时，只用到已经计算出的 m(i, k) 与 m(k+1, j)。

    PPT 第 27 页的措辞值得记：当计算表项 m[i, j] 时，会用到乘积 pi−1pkpj（k = i, i+1, …, j−1），以及 m[i, j] 西南方向和东南方向的所有表项。

    伪代码（PPT 第 28 页）

    MATRIX-CHAIN-ORDER(P)                // P = p0..pn，Ai 的规模是 p(i−1)×p(i)
1  n = len(P) − 1                    // 矩阵个数 n
2  for i = 1 to n                    // 初始化对角线
3      m[i, i] = 0                    // 单个矩阵不需要乘法
4  for L = 2 to n                    // 按矩阵链长度 L 递增
5      for i = 1 to n − L + 1        // 链的起点 i
6          j = i + L − 1              // 链的终点 j
7          m[i, j] = ∞                // 先置为正无穷
8          for k = i to j − 1         // 枚举断点 k
9              q = m[i, k] + m[k+1, j] + p(i−1)·p(k)·p(j)   // 候选代价
10             if q < m[i, j]          // 找到更小的代价
11                 m[i, j] = q        // 更新最优值
12                 s[i, j] = k        // 记下最优断点
13 return m and s                    // 返回最优值表和断点表

    C++

    const int INF = 0x7fffffff;                        // 用一个很大的数表示"无穷"
int m[7][7], s[7][7];                              // m 存最少乘次数，s 存最优断点

void matrixChainOrder(int p[], int n) {            // p 长度 n+1，Ai 规模 p[i-1]×p[i]
    for (int i = 1; i <= n; ++i) { m[i][i] = 0; }   // 单个矩阵不需要乘法
    for (int L = 2; L <= n; ++L) {                 // 按链长 L = 2..n 递增
        for (int i = 1; i <= n - L + 1; ++i) {      // 链的起点 i
            int j = i + L - 1;                     // 链的终点 j
            m[i][j] = INF;                         // 先置为正无穷
            for (int k = i; k < j; ++k) {          // 枚举断点 k
                int q = m[i][k] + m[k + 1][j] + p[i - 1] * p[k] * p[j];   // 候选代价
                if (q < m[i][j]) {                 // 找到更小的代价
                    m[i][j] = q;                   // 更新最优值
                    s[i][j] = k;                   // 记下最优断点
                }                                  // 结束比较
            }                                      // 结束断点枚举
        }                                          // 结束起点枚举
    }                                              // 结束链长枚举
}                                                  // 结束 matrixChainOrder

    5. 习题 3：最长公共子序列（LCS）

    5.1 定义与两个例子

    最长公共子序列（longest common subsequence, LCS）

    给定两个序列 x[1..m] 和 y[1..n]，找出它们两者的一个最长公共子序列。

    注意"子序列"（subsequence）不要求字符连续，只要求相对次序不变；这与"子串"（substring，必须连续）不同（此处区分为补充说明）。

    例 1（PPT 第 41 页）：A = "HelloWorld"，B = "loop"，则 A 与 B 的最长公共子序列为 "loo"，返回的长度为 3（H-e-l-l-o-W-o-r-l-d 里依次取第 3、4、5 个字符 l, o, o）。

    例 2（PPT 第 42~43 页）：x = A B C B D A B（m = 7），y = B D C A B A（n = 6）。它们的 LCS 是 BCBA，长度为 4；BDAB 也是一个 LCS（PPT 第 43 页备注）。本例的 c 表与 b 表就是下面 5.8 节要逐格填的那两张表。

    5.2 野蛮算法：为什么必须换思路

    PPT 第 44~45 页的野蛮算法：检查 x[1..m] 的每个子序列，看它是否为 y[1..n] 的一个子序列。

    • 对每个子序列，检查需要 O(n) 时间；
    • 序列 x 有 2m 个子序列（每个长度为 m 的位矢量对应一个子序列）；
    • 最坏情况下的运行时间 = O(n·2m) —— 指数时间。

    5.3 向更好的算法努力：只先算"长度"

    PPT 第 46~47 页的简化思路：先只观察一个最长公共子序列的长度，再扩展算法找出 LCS 本身。记 |s| 表示序列 s 的长度，策略是考虑 x 和 y 的前缀：

    c[i, j] = | LCS( x[1..i], y[1..j] ) |   ⇒   c[m, n] = | LCS(x, y) |

    也就是把"两个前缀"作为子问题：i 和 j 各有 m+1、n+1 种取值，所以不同子问题最多 (m+1)(n+1) = O(mn) 个 —— 多项式。这就是 DP 的立足点。

    5.4 最优子结构：三条定理与证明

    定理（LCS 的最优子结构，PPT 第 49 页逐字）

    令 X = x[1..m] 和 Y = y[1..n] 为两个序列，Z = z[1..k] 为 X 和 Y 的任意 LCS。

    1. 如果 x[m] = y[n]，则 z[k] = x[m] = y[n] 且 Zk−1 是 Xm−1 和 Yn−1 的一个 LCS；
    2. 如果 x[m] ≠ y[n]，则 z[k] ≠ x[m] 意味着 Z 是 Xm−1 和 Y 的一个 LCS；
    3. 如果 x[m] ≠ y[n]，则 z[k] ≠ y[n] 意味着 Z 是 X 和 Yn−1 的一个 LCS。

    情况 ① 的证明（PPT 第 51 页，剪贴并且拷贝 cut & paste）：

    用反证法。假设 w 是 x[1..m−1] 和 y[1..n−1] 一个更长的 LCS，即 |w| > k−1。那么，剪贴并且拷贝：w ‖ z[k]（w 与 z[k] 连接）是 x[1..m] 和 y[1..n] 的公共子序列，同时 |w ‖ z[k]| > k。这与 "Z 是长度为 k 的 LCS" 自相矛盾，由此该声明得证。其他情况类似。∎

    情况 ② 的证明（SPEC 要求，剪贴 + 反证）：

    已知 x[m] ≠ y[n] 且 z[k] ≠ x[m]。

    1. 先证 Z 是 Xm−1 与 Y 的公共子序列：Z 本来就是 X 与 Y 的公共子序列。因为 z[k] ≠ x[m]，Z 的全部字符都来自 x[1..m−1]（X 去掉末字符 x[m] 后仍完整包含 Z），而 Y 不变，所以 Z 也是 Xm−1 与 Y 的公共子序列。
    2. 再证它最长：若 Xm−1 与 Y 存在更长的公共子序列 W（|W| > k），那么 W 当然也是 X 与 Y 的公共子序列（Xm−1 是 X 的前缀），于是 X 与 Y 有长度大于 k 的公共子序列，与 |LCS(X,Y)| = k 矛盾。

    故 Z 是 Xm−1 与 Y 的一个 LCS。情况 ③ 对称（把 X 与 Y 互换）。∎

    5.5 递归公式

    c[i, j] = c[i−1, j−1] + 1   （若 x[i] = y[j]）；   c[i, j] = max{ c[i−1, j], c[i, j−1] }   （其他）

    用文字说（PPT 第 52 页）：

    • 如果 x[m] = y[n]，我们应该求解 Xm−1 和 Yn−1 的一个 LCS（再把 x[m] 接在末尾）；
    • 如果 x[m] ≠ y[n]，我们必须求解两个子问题：求 Xm−1 和 Y 的一个 LCS；求 Xm 和 Yn−1 的一个 LCS，取二者较长者。

    5.6 递归算法、递归树与重叠子问题

    5.7 备忘录算法：只在表里没有时递归

    PPT 第 61~63 页：备忘录（memoization）—— 在计算出一个子问题的答案后，将其存储在表中；此后调用将检查表，以避免重复工作。

    伪代码（PPT 第 62 页，按第 61 页说明补全）

    LCS-MEMO(x, y, i, j)                 // 求 LCS(x[1..i], y[1..j]) 的长度
1  if c[i, j] = NIL                  // 表里还没有这个子问题的答案
2  then if x[i] = y[j]                // 两个末字符相同（和以前一样）
3           c[i, j] = LCS-MEMO(x, y, i−1, j−1) + 1   // 左上子问题 + 1
4       else c[i, j] = max( LCS-MEMO(x, y, i−1, j),   // 丢掉 x 的末字符
5                          LCS-MEMO(x, y, i, j−1) )   // 丢掉 y 的末字符
6  return c[i, j]                     // 返回（可能是刚算好并存表的）值

    C++

    int memo[8][7];                                // 备忘表，−1 表示"还没算过"
int lcsMemo(char x[], char y[], int i, int j) { // 求 LCS(x[1..i], y[1..j]) 的长度
    if (i == 0 || j == 0) { return 0; }         // 边界：任一前缀为空则长度为 0
    if (memo[i][j] >= 0) { return memo[i][j]; } // 查表命中就直接返回
    if (x[i] == y[j]) {                         // 两个末字符相同：左上子问题 + 1
        memo[i][j] = lcsMemo(x, y, i - 1, j - 1) + 1;   // 左上子问题的长度再加 1
    } else {                                    // 末字符不同：取两个子问题的较大者
        int a = lcsMemo(x, y, i - 1, j);        // 丢掉 x 的末字符
        int b = lcsMemo(x, y, i, j - 1);        // 丢掉 y 的末字符
        memo[i][j] = (a > b) ? a : b;           // 取较大的长度
    }                                           // 结束分支
    return memo[i][j];                          // 返回并存表
}                                               // 结束 lcsMemo

    复杂度（PPT 第 63 页）：时间 = Θ(mn)（每个表项常量工作）；空间 = Θ(mn)。

    5.8 自底向上：LCS-LENGTH 与 c / b 两张表

    PPT 第 71 页的 LCS-LENGTH(X, Y)。填表顺序的依据是：为了计算 c[i, j]，我们需要 c[i−1, j−1]、c[i−1, j] 和 c[i, j−1] —— 三者都在左上方，所以按行优先、从上到下、从左到右填即可。b[i, j] 指向表中（计算 c[i, j] 时）选择的最优方案。

    伪代码（PPT 第 71 页 17 行）

    5.9 延伸一：关于最优子结构的判定（无权最长路径没有最优子结构）

    PPT 第 73 页提出一个问题：给定有向图 G = (V, E) 和两个顶点 u, v，考虑下面两个问题是否具有最优子结构 ——

    • 无权最短路径：找到一条从 u 到 v 边数最少的路径；
    • 无权最长路径：找到一条从 u 到 v 的边数最多的简单路径。

    答案：最短路径有最优子结构（若 u → … → w → v 最短，则 u → … → w 必是 u 到 w 的最短路径，剪贴法即可证）；无权最长路径没有最优子结构 —— 而且问题比"不最优"更严重：子问题的解的组合甚至都不是原问题的合法解（PPT 第 74 页）。

    图 5  无权最长简单路径的反例（PPT 第 74 页 image33.png）与"子问题无关"的解释

    子问题无关（PPT 第 75 页）

    同一个原问题的一个子问题的解不影响另一个子问题的解 —— 最短路径的子问题"相互不共享资源"（不共享顶点），所以 u→w 的最短路径与 w→v 的最短路径可以直接拼接；而最长路径的两个子问题会争用顶点，拼接后可能不再是简单路径，甚至不是路径。

    结论：判断一个问题能否用 DP，除了"最优子结构 + 重叠子问题"，还要检查子问题是否无关（是否会被同一个资源卡住）。

    5.10 延伸二：最长上升子序列（LIS）

    PPT 第 76 页：最长上升子序列（longest increasing subsequence），也可以叫最长非降序子序列，简称 LIS。例：6 个数分别是 1 7 6 2 3 4，求最长上升子序列。

    答案：1 2 3 4，长度 4。（1 7 只有 2；1 6 之后没有更大的；只有 1 2 3 4 能取到 4 个。）

    DP 做法（O(n2)）：定义 d[i] = 以 a[i] 结尾的 LIS 长度，则

    d[i] = 1 + max{ d[j] : j < i 且 a[j] < a[i] }   ，   LIS 长度 = maxi d[i]

    伪代码

    LIS(a, n)                            // 求长度（若要输出序列，另存前驱 pre[]）
1  for i = 1 to n                    // 逐个元素求 d[i]
2      d[i] = 1                       // 至少可以只取 a[i] 自己
3      for j = 1 to i − 1            // 枚举 i 之前的所有位置
4          if a[j] < a[i] and d[j] + 1 > d[i]   // 能接在 j 后面且更长
5              d[i] = d[j] + 1        // 更新 d[i]
6              pre[i] = j             // 记下前驱，便于输出方案
7  ans = max(d[1..n])                // 全局最长
8  return ans                        // 返回 LIS 长度

    C++

    int lis(int a[], int n) {                      // 返回最长上升子序列的长度
    int d[101], ans = 0;                       // d[i]：以 a[i] 结尾的 LIS 长度
    for (int i = 1; i <= n; ++i) {             // 逐个元素求 d[i]
        d[i] = 1;                              // 至少可以只取 a[i] 自己
        for (int j = 1; j < i; ++j) {          // 枚举 i 之前的所有位置
            if (a[j] < a[i] && d[j] + 1 > d[i]) {   // 能接在 j 后面且更长
                d[i] = d[j] + 1;               // 更新 d[i]
            }                                  // 结束判断
        }                                      // 结束枚举 j
        if (d[i] > ans) { ans = d[i]; }        // 更新全局最长
    }                                          // 结束枚举 i
    return ans;                                // 返回 LIS 长度
}                                              // 结束 lis

    记忆：LIS 的 O(n log n) 做法（思路，补充）

    维护一个数组 tail[]：tail[k] 表示"长度为 k+1 的上升子序列的最小可能结尾值"。tail 天然单调递增，于是对每个 a[i] 在 tail 里二分找第一个 ≥ a[i] 的位置并替换它（找不到就追加）。总时间 Θ(n log n)，空间 Θ(n)。注意：这个方法只能求长度，要输出具体序列仍需记录前驱。

    本节考点

    ① LCS 定义与两个例子（"loo" 长度 3；BCBA 长度 4，BDAB 也行）；② 野蛮算法 O(n·2m)；③ 三条最优子结构定理 + 剪贴法证明；④ 递归式 c[i,j] = c[i−1,j−1]+1 或 max(c[i−1,j], c[i,j−1])；⑤ 重叠子问题只有 mn 个 → 备忘录 Θ(mn)；⑥ 自底向上填 c、b 两表，c[7,6] = 4，回溯 O(m+n) 得 BCBA；⑦ 无权最长路径无最优子结构（子问题相关）；⑧ LIS：1 7 6 2 3 4 → 1 2 3 4，长度 4。

    6. 习题 4：装配线调度（assembly-line scheduling）

    6.1 问题模型

    一个汽车机架进入一条生产线，在每个工作站增加一些配件，最后在装配线结束，完成的汽车下线（PPT 第 77 页）。有 2 条装配线 × n 个工作站：

    记号含义
    Si,j生产线 i 上的第 j 个工作站（i = 1, 2；j = 1, …, n）
    ai,j工作站 Si,j 需要的装配时间
    ti,j每条线上从工作站 Si,j 到另外一条线上的第 j+1 个站的传输时间
    ei / xi生产线 i 上从上线到进入第 1 站、以及从第 n 站到下线的时间

    目标：确定选择哪些工作站，使得制造一台汽车总的时间最小化。

    蛮力法：Ω(2n) —— 为什么？因为经过每一站时都有"留在这条线"或"换到另一条线"两种选择，n 站就是 2n 条候选路线。而问题是线性有序的（从左到右一站一站走）⇒ 适合动态规划。

    图 6  两条装配线的结构（PPT 第 77 页示意图）与最快路径

    6.2 步骤一：最优子结构

    最优子结构（PPT 第 78 页）

    假设经 S1,j 最快的线路通过 S1,j−1，那么装配机架必定利用了从开始点到 S1,j−1 的最快路径。

    证明（剪贴法）：若不利用最快路径，用那条更快的路径替换前缀，整条路线会更快，矛盾。对线 2 与"从另一条线换过来"的情形同理。所以问题具有最优子结构，并且由于"问题是线性有序的"，适合 DP。

    6.3 步骤二：递归式（重叠子问题）

    PPT 第 79 页：既然通过 S1,j 最快的路线要么是通过 S1,j−1 然后是 S1,j，要么是通过 S2,j−1 然后传输到线 1 到达 S1,j，就有：

    记 fi[j] = 从开始点通过 Si,j 的最快时间：

    f1[1] = e1 + a1,1   ，   f2[1] = e2 + a2,1

    f1[j] = min( f1[j−1] + a1,j ,   f2[j−1] + t2,j−1 + a1,j )   (j ≥ 2)

    f2[j] = min( f2[j−1] + a2,j ,   f1[j−1] + t1,j−1 + a2,j )   (j ≥ 2)

    f* = min( f1[n] + x1 ,   f2[n] + x2 )

    同时用 li[j] 记录"以最快路线通过 Si,j 时，第 j−1 个站所在的线号"（即前驱线号），用 l* 记录最后从哪条线下线。这样 f* 给出最优值，l 表给出最优解。

    int a1[7] = {0, 7, 9, 3, 4, 8, 4};             // 线 1 各站的装配时间
int a2[7] = {0, 8, 5, 6, 4, 5, 7};             // 线 2 各站的装配时间

void fastestWay(int n) {                       // n 个工作站
    f1[1] = 2 + a1[1];                         // 第 1 条线第 1 站：上线 2 + 装配 7 = 9
    f2[1] = 4 + a2[1];                         // 第 2 条线第 1 站：上线 4 + 装配 8 = 12
    for (int j = 2; j <= n; ++j) {             // 从第 2 站递推到第 n 站

            f1[j] = f1[j - 1] + a1[j];         // 记录线 1 的最快时间
            l1[j] = 1;                         // 前驱仍在第 1 条线
        } else {                               // 从线 2 换线过来更快
            f1[j] = f2[j - 1] + t2[j - 1] + a1[j];   // 加上换线传输时间
            l1[j] = 2;                         // 前驱是第 2 条线
        }                                      // 结束分支
        if (f2[j - 1] + a2[j] <= f1[j - 1] + t1[j - 1] + a2[j]) {   // 留在原线更快
            f2[j] = f2[j - 1] + a2[j];         // 记录线 2 的最快时间
            l2[j] = 2;                         // 前驱仍在第 2 条线
        } else {                               // 从线 1 换线过来更快
            f2[j] = f1[j - 1] + t1[j - 1] + a2[j];   // 加上换线传输时间
            l2[j] = 1;                         // 前驱是第 1 条线
        }                                      // 结束分支
    }                                          // 结束递推
    if (f1[n] + 3 <= f2[n] + 2) {              // 比较两条线的出口总时间
        fstar = f1[n] + 3; lstar = 1;          // 走线 1 下线（x1 = 3）
    } else {                                   // 否则走线 2 下线
        fstar = f2[n] + 2; lstar = 2;          // 走线 2 下线（x2 = 2）
    }                                          // 结束比较
}                                              // 结束 fastestWay

    7. 习题 5：最优二叉搜索树（OBST）

    7.1 定义与记号

    给定一个序列 K = ⟨k1, k2, …, kn⟩，有 n 个有序且各不相同的键（k1 < k2 < … < kn），集合 P = ⟨p1, p2, …, pn⟩ 表示在 K 中成功搜索的概率；D = ⟨d0, d1, d2, …, dn⟩ 为 n+1 个不同的哑键（di 表示所有在 ki 和 ki+1 之间的值），Q = ⟨q0, q1, q2, …, qn⟩ 表示不成功搜索的概率。创建二叉搜索树，使得其期望搜索花费最小（PPT 第 90 页）。

    二叉搜索树（二叉排序树）：或者是一棵空树，或者是具有下列性质的二叉树 —— 若左子树不空，则左子树上所有结点的值均小于根结点的值；若右子树不空，则右子树上所有结点的值均大于根结点的值；左右子树也分别为二叉排序树（PPT 第 90 页备注）。

    对一棵树 T，一次搜索的期望代价为

    E[T] = ∑i=1..n pi · (depth(ki) + 1) + ∑i=0..n qi · (depth(di) + 1)

    （深度从 0 起算，"+1"表示比较次数 = 深度 + 1。这正是 PPT 第 91 页那些 0.10×1、0.15×2 乘式的来源。）

    7.3 步骤一：最优子结构

    最优子结构（PPT 第 92 页）

    如果一棵最优二叉搜索树 T 的子树 T' 含有键 ki, …, kj，那么这个子树 T' 肯定是子问题"键 ki, …, kj 和哑键 di−1, …, dj"的最优解（PPT 注明"请自行证明"，用剪贴法）。

    解的结构：给定键 ki, …, kj，以 kr（i ≤ r ≤ j）为根，其左子树包括键 ki, …, kr−1（和哑键 di−1, …, dr−1），右子树包括键 kr+1, …, kj（和哑键 dr, …, dj）。

    对于"包括键 ki, …, ki 和根 ki"的子树，左子树包括键 ki, …, ki−1（没有键）和哑键 di−1。

    7.4 步骤二：递归式

    记 e[i, j] = 搜索一棵包括键 ki, …, kj 的最优二叉搜索树的期望费用，希望找出 e[1, n]。

    边界（只有哑键 di−1）：

    e[i, i−1] = qi−1

    如果 kr（i ≤ r ≤ j）是包括键 ki, …, kj 的最优子树的根，并且令

    e[i, j] = pr + ( e[i, r−1] + w(i, r−1) ) + ( e[r+1, j] + w(r+1, j) ) = e[i, r−1] + e[r+1, j] + w(i, j)

    其中 w(i, j) 是区间 [i, j] 内所有键与哑键的概率之和，可按

    w(i, j) = w(i, j−1) + pj + qj

    迭代计算（PPT 第 94 页问"为什么"）：因为 w(i, j) 只在 w(i, j−1) 上加两项，O(1) 就能算出来，不必每次重新累加（否则会多一层 O(n) 求和，总复杂度升到 O(n4)）。于是递归式为：

    e[i, j] = mini ≤ r ≤ j { e[i, r−1] + e[r+1, j] + w(i, j) }   （i ≤ j）

    用 root[i, j] 记录索引 r —— 它对应 kr 为最优搜索树的根，该树包括键 ki, …, kj。

    7.5 OPTIMAL-BST 伪代码 + C++

    伪代码（PPT 第 94 页）

    OPTIMAL-BST(p, q, n)                 // n 个真实键，n+1 个哑键
1  for i ← 1 to n + 1                // 初始化所有空区间
2      e[i, i−1] ← q(i−1)            // 只有哑键 d(i−1)
3      w[i, i−1] ← q(i−1)            // 权重也等于 q(i−1)
4  for l ← 1 to n                    // 按区间长度 l 递增
5      for i ← 1 to n − l + 1        // 区间起点 i
6          j ← i + l − 1             // 区间终点 j
7          e[i, j] ← ∞               // 先置为正无穷
8          w[i, j] ← w[i, j−1] + p(j) + q(j)   // 递推权重
9          for r ← i to j            // 枚举根 k(r)
10             t ← e[i, r−1] + e[r+1, j] + w[i, j]   // 候选费用
11             if t < e[i, j]        // 更小的费用
12                 e[i, j] ← t       // 更新最优值
13                 root[i, j] ← r    // 记下最优根
14 return e and root                 // 返回费用表与根表

    C++

    double p5[6] = {0, 0.15, 0.10, 0.05, 0.10, 0.20};     // 5 个键的成功概率
double q5[6] = {0.05, 0.10, 0.05, 0.05, 0.05, 0.10};   // 6 个哑键的失败概率
double e[7][6], w[7][6];                               // e 存期望费用，w 存区间权重
int root[7][6];                                        // root 存最优根的下标

void optimalBst(int n) {                       // n 个真实键，n+1 个哑键
    for (int i = 1; i <= n + 1; ++i) {         // 初始化所有空区间
        e[i][i - 1] = q5[i - 1];               // 只有哑键 d(i−1) 的期望费用
        w[i][i - 1] = q5[i - 1];               // 只有哑键 d(i−1) 的权重
    }                                          // 结束空区间初始化
    for (int l = 1; l <= n; ++l) {             // 按区间长度 l 递增
        for (int i = 1; i <= n - l + 1; ++i) { // 区间起点 i
            int j = i + l - 1;                 // 区间终点 j
            e[i][j] = 1e18;                    // 先置为一个很大的数
            w[i][j] = w[i][j - 1] + p5[j] + q5[j];   // O(1) 递推区间权重
            for (int r = i; r <= j; ++r) {     // 枚举根 k(r)
                double t = e[i][r - 1] + e[r + 1][j] + w[i][j];   // 候选费用
                if (t < e[i][j]) {             // 找到更小的费用
                    e[i][j] = t;               // 更新最优值
                    root[i][j] = r;            // 记下最优根
                }                              // 结束比较
            }                                  // 结束根枚举
        }                                      // 结束起点枚举
    }                                          // 结束长度枚举
}                                              // 结束 optimalBst

    7.7 复杂度

    • 时间：三层循环（长度 l、起点 i、根 r），每层 O(n)，共 Θ(n3)。关键前提是 w(i,j) 用递推 O(1) 算出。
    • 空间：e、w、root 各 (n+1) × (n+1)，共 Θ(n2)。
    • PPT 第 94 页的两个"为什么"：e 表为什么需要 e[1..n+1, 0..n] —— 因为要容纳 e[i, i−1] 这类空区间（i = n+1、j = 0）的边界值；w 为什么要迭代 —— 见 7.4 节。

    本节考点

    ① 定义：n 个有序键 + n+1 个哑键，成功概率 pi、失败概率 qi；② 期望代价公式（深度 + 1 加权）；③ 算例最优费用 2.75（另一棵树 2.80）；④ 最优子结构：子树必为相应子问题最优解；⑤ 递推 e[i,i−1] = qi−1、e[i,j] = minr{e[i,r−1]+e[r+1,j]+w(i,j)}、w(i,j) = w(i,j−1)+pj+qj；⑥ 时间 Θ(n3)、空间 Θ(n2)，用 root 表重建树。

    8.2 课堂练习 1：用动态规划计算斐波那契数列

    题目（PPT 第 96 页）：针对斐波那契数列 F(0) = 0、F(1) = 1、F(n) = F(n−1) + F(n−2)，如何使用动态规划法计算 F(n)？请给出算法每个步骤的思想和算法伪代码。

    四个步骤的落地：

    1. 刻画结构特征：F(n) 的最优值（这里就是"值"本身）由 F(n−1) 与 F(n−2) 决定 —— 最优子结构；
    2. 递归定义值：F(n) = F(n−1) + F(n−2)，边界 F(0) = 0、F(1) = 1；
    3. 计算值：按 i = 2, 3, …, n 递增（逆拓扑序）填表 f[i]；
    4. 构造解：本题只要求值，第 4 步可省略（若要输出整个数列，表本身就是解）。

    伪代码

    FIB-DP(n)                            // 自底向上求 F(n)
1  let f[0..n] be a new array         // 建表，f[i] 存 F(i)
2  f[0] = 0                           // 边界 F(0) = 0
3  if n ≥ 1 then f[1] = 1             // 边界 F(1) = 1
4  for i = 2 to n                     // 按规模递增（逆拓扑序）填表
5      f[i] = f[i−1] + f[i−2]         // 直接查表，不再递归
6  return f[n]                        // 返回 F(n)

    C++（滚动数组，空间 O(1)）

    long long fibDp(int n) {                       // 自底向上计算 F(n)
    if (n == 0) { return 0; }                  // 边界 F(0) = 0
    if (n == 1) { return 1; }                  // 边界 F(1) = 1
    long long a = 0, b = 1, t;                 // a = F(i−2)，b = F(i−1)
    for (int i = 2; i <= n; ++i) {             // 从 i = 2 递推到 i = n
        t = a + b;                             // 递推式：F(i) = F(i−1) + F(i−2)
        a = b;                                 // 滚动：a 变成 F(i−1)
        b = t;                                 // 滚动：b 变成 F(i)
    }                                          // 结束递推
    return b;                                  // 返回 F(n)
}                                              // 结束 fibDp

    前 11 项（可用上面的程序验证，F(20) = 6765）：

    n012345678910
    F(n)011235813213455

    为什么这样就快了？朴素递归 FIB(n) = FIB(n−1) + FIB(n−2) 的子问题大量重叠（F(3) 算 2 次、F(2) 算 3 次、F(1) 算 5 次），调用次数按 Θ1.618n 增长（指数）；而不同子问题只有 n+1 个，自底向上填表是 Θ(n) 时间、Θ(n) 空间，滚动数组后空间降到 Θ(1)。

    9.2 一页速记

    四个步骤 + 两个要素 + 两种实现

    1. 四步：① 刻画最优解的结构（最优子结构）② 递归定义最优解的值 ③ 计算最优解的值（通常自底向上）④ 利用信息构造最优解；
    2. 两要素：最优子结构（标志 #1）+ 重叠子问题（标志 #2）；另外要检查子问题无关（否则像无权最长路径一样失效）；
    3. 两种实现：带备忘的自顶向下（用到才算）/ 自底向上（按逆拓扑序全算），二者等价，按"是否所有子问题都要算"来选；
    4. 实质：分治思想 + 解决冗余 —— 第一次遇到时求解并存表，以后查表。

    五个问题的"一句话记忆"

    • 钢条切割：切下第一段 i，剩下 n−i 查表 → r4 = 10（2+2）；
    • 矩阵链：按链长递增填表，断点 k 两边都最优 → m(1,6) = 15125；
    • LCS：末字符相等「左上 + 1」，否则「上、左取大」→ c[7,6] = 4，BCBA；
    • 装配线：每站二选一（留下 / 换线）→ f* = 38，路径 1-1 → 2-2 → 1-3 → 2-4 → 2-5 → 1-6；
    • OBST：根 r 左右都最优，权重 w(i,j) 迭代算 → e[1,5] = 2.75。

    9.3 常见错误清单

    错误正确做法
    把 programming 理解成"写程序"是表格法（tabular method）
    钢条切割写成 rn = max(ri + rn−i) 却只枚举一半写 rn = max1≤i≤n(pi + rn−i)；两个 r 的版本要枚举全部 n−1 个断点
    矩阵链按行优先（i 递增、j 递增）填表必须按链长 L 递增，否则 m(i,k)、m(k+1,j) 还没算
    LCS 的 b[i,j] 平局时随便取按 PPT 的规则：相等时走"上"（c[i−1,j] ≥ c[i,j−1]），否则"左"；平局不同会得到不同的 LCS，但长度相同
    装配线把 t2,j−1 写成 t2,j换线是从第 j−1 站换到第 j 站，用 t·,j−1
    OBST 每次都重新累加 w(i,j)用 w(i,j) = w(i,j−1) + pj + qj 递推，否则复杂度升到 O(n4)
    见到"最优化"就上 DP先检查最优子结构 + 重叠子问题 + 子问题无关，还要看子问题规模是否可接受（n!、2n 就放弃）

    动态规划 = 把"递归"里重复出现的子问题答案存进一张表，并按逆拓扑序把表填满。五个习题只是同一件事的五种外衣：钢条切割是一维表（按长度），矩阵链与 OBST 是二维区间表（按区间长度），LCS 是二维前缀表（按行列），装配线是两条一维表（按站号）。认准"表怎么定义、按什么顺序填、需要哪张辅助表来构造解"，这一讲就通了。

    答案：A、C、D　A 对：填完 c 表后从 b[m,n] 沿箭头回溯，每步至少让 i 或 j 减 1，最多 m+n 步，故 O(m+n)；B 错：LCS 的最优子结构定理（三种情形）正是它的 DP 基础；C 对：不同子问题共 mn 个，备忘录每个表项 O(1)，时间空间均 Θ(mn)；D 对：朴素递归树高 m+n、工作量指数级，但真正不同的子问题只有 mn 个 —— 大量重复正是「DP 标志 #2」。

    3. 关于最优二叉搜索树问题，下列说法正确的有哪些？动态规划 · 原卷 11

    • A. 输入键按从小到大排列
    • B. root[i][j] 只记录最小费用而不记录根
    • C. p 表示成功搜索概率，q 表示不成功搜索概率
    • D. e[i, i−1] = q(i−1)

    答案：A、C、D　A 对：键满足 k1<k2<…<kn，这是构造 BST 的前提；B 错：最小费用存在 e[i][j] 里，root[i][j] 存的恰恰是取到该最小值的根下标 r（只有存了根才能构造出树）；C 对：pi 是命中 ki 的概率、qi 是落在哑键 di 的概率；D 对：区间为空时只剩哑键 di−1，代价就是 qi−1（初始化 e[i][i-1] ← qi-1）。

    4. 关于装配线调度问题，下列说法正确的有哪些？动态规划 · 原卷 13

    • A. li[j] 可记录最快路线中前一站所在线号
    • B. 最快时间为 min(f1[n]+x1, f2[n]+x2)
    • C. 蛮力法的时间下界为 Ω(2n)
    • D. 问题限制制造过程只能使用一条生产线

    答案：A、B、C　A 对：l1[j]、l2[j] 记录到达 Si,j 的最快路线来自哪条线，供 PRINT-STATION 回溯；B 对：最后要各自加上下线时间 x1、x2 再取小；C 对：每个工作站都要决定走哪条线，共 2n 种走法，蛮力是 Ω(2n)；D 错：两条线可以互相换线，换线时间 ti,j 正是为「换线」建模的。

    5. 最优二叉搜索树算法中，root[i][j] 记录包含键 ki 到 kj 的最优子树的 ______。动态规划 · 原卷 18

    答案：根节点索引 r（即使 e[i][j] 取到最小值的那个根 kr 的下标）。分工要分清：e[i][j] 存最小的期望搜索费用（数值），root[i][j] 存取得该最小值的根 kr 的下标 r。有了 root 表，才能从 root[1][n] 出发递归地取 (i, r−1) 与 (r+1, j) 还原整棵最优树 —— 这就是「DP 第 4 步：利用计算出的信息构造最优解」。

    6.（计算题）装配线有 3 个工作站，e1=2、e2=3，a1=(4,5,3)、a2=(6,4,5)，换线时间 t1,1=2、t1,2=1、t2,1=1、t2,2=3，下线时间 x1=4、x2=2，则最快总时间为 ______。动态规划 · 原卷 19

    答案：18　逐站递推（fi[j] = 从上线到经过 Si,j 的最快时间）：
    ① f1[1]=e1+a1,1=2+4=6，f2[1]=e2+a2,1=3+6=9；
    ② f1[2]=min(f1[1]+a1,2, f2[1]+t2,1+a1,2)=min(6+5, 9+1+5)=11， f2[2]=min(f2[1]+a2,2, f1[1]+t1,1+a2,2)=min(9+4, 6+2+4)=12；
    ③ f1[3]=min(11+3, 12+3+3)=14，f2[3]=min(12+5, 11+1+5)=17；
    ④ f* = min(f1[3]+x1, f2[3]+x2)=min(14+4, 17+2)=18（走线 1 下线）。
    即 f1=(6,11,14)、f2=(9,12,17)，与课件答案一致。注意 t 的下标：从线 2 换到线 1 的 j 站用 t2,j−1。
