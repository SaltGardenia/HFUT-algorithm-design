    考点速查表

    把最容易考、最容易记混的结论集中在这里，串讲前一天过一遍即可。

    一、算法的三大性质

    性质含义PPT 反例正例（选择排序）
    有穷性
    Finiteness    		 算法必须在有限个计算步骤后终止 给定输入数组，不断交换首尾元素的位置（动作序列没有终结） 遍历次数至多与数组元素个数相同
    确定性
    Definiteness    		 算法必须是没有歧义的，每个步骤都是确定的 对于给定输入数组，交换两个数的位置（没有具体指明是哪两个数） 第 1 次遍历找最小、第 2 次找次小 …… 第 n 次找第 n 小
    可行性
    Effectiveness    		 可以机械地一步一步执行基本操作步骤 将大元素放数组后部、小元素放数组前部（描述含糊，不可拆解为基本操作步骤） 算法可一步步地执行完成

    二、算法分析的三条原则

    1. 独立于机器：机器运算速度影响运行时间，跨机器比较不公平（PPT 例：天河三号百亿亿次/秒跑插入排序 vs 个人电脑十亿次/秒跑选择排序 → 无法公平比较）。
    2. 归纳基本操作、代价统一为 1：算术运算 + − × ÷ 与赋值比较 ≔ > < =，假设基本操作代价均为 1。
    3. 分析最坏情况：统一机器性能后，运行时间只依赖问题输入规模 n 与具体实例；最好情况不常出现、不具普遍性，一般情况分析难度大，故常用最坏情况分析。

    算法运行时间仅依赖于问题输入规模 n，表示为 T(n)

    三、五种渐近记号

    记号名称严格定义与实数比较类比
    Θ(g(n))渐近紧确界 ∃ c1, c2, n0 > 0，∀ n ≥ n0：0 ≤ c1g(n) ≤ f(n) ≤ c2g(n) f = Θ(g) ≈ a = b
    O(g(n))渐近上界 ∃ c, n0 > 0，∀ n ≥ n0：0 ≤ f(n) ≤ cg(n) f = O(g) ≈ a ≤ b
    Ω(g(n))渐近下界 ∃ c, n0 > 0，∀ n ≥ n0：0 ≤ cg(n) ≤ f(n) f = Ω(g) ≈ a ≥ b
    o(g(n))渐近非紧上界 ∀ c > 0，∃ n0，∀ n ≥ n0：0 ≤ f(n) < cg(n) f = o(g) ≈ a < b
    ω(g(n))渐近非紧下界 ∀ c > 0，∃ n0，∀ n ≥ n0：0 ≤ cg(n) < f(n) f = ω(g) ≈ a > b

    必背等价关系

    f(n) = Θ(g(n))  当且仅当  f(n) = O(g(n)) 且 f(n) = Ω(g(n))。

    因为 Θ(g(n)) ⊆ O(g(n))，所以 Θ 强于 O：f(n)=Θ(g(n)) ⇒ f(n)=O(g(n))。

    算法运行时间称为时间复杂度，通常用渐近记号 O 表示。

    四、求解递归式三法

    方法核心思路适用与提醒
    代换法 ① 猜测解的形式 → ② 通过推导验证 → ③ 解出常数 最通用；必须处理初始条件；猜测不准会卡住（如直接猜 O(n²) 失败，需减去低阶项加强假设）
    递归树 对递归执行的花费建模，逐层求和 可为代换法提供猜想；不太可靠但有启发作用
    主方法 比较 f(n) 与 nlogba 仅适用于 T(n) = aT(n/b) + f(n)（a ≥ 1, b > 1）；情况 3 还需正则化条件

    五、主方法三种情况

    适用于 T(n) = aT(n/b) + f(n)，其中 a ≥ 1、b > 1 为常数，f(n) 是渐近正函数。比较基准是 nlogba。

    情况条件递归树加权分布结论
    情况 1 f(n) = O(nlogba − ε)，常量 ε > 0
    （f 比基准增长慢，慢 nε 倍）    		 从根到叶子几何级数增长，叶子仅占常量部分 T(n) = Θ(nlogba)
    情况 2 f(n) = Θ(nlogba) 每层加权基本相同 T(n) = Θ(nlogba lg n) = Θ(f(n) lg n)
    情况 3 f(n) = Ω(nlogba + ε)，常量 ε > 0
    （f 比基准增长快）
    且 f(n) 满足正则化条件 a·f(n/b) ≤ c·f(n)，常量 c < 1    		 从根到叶子几何级数递减，根仅占常量部分 T(n) = Θ(f(n))

    六、两个排序算法的复杂度（PPT 逐行计数结论）

    算法最好情况最坏情况逐行计数结果渐近
    插入排序 数组已升序：比较 1+1+…+1 = n − 1 次 数组已降序：比较 1+2+…+(n−1) = n(n−1)/2 次 T(n) = 3n²/2 + 7n/2 − 4 Θ(n²)
    选择排序 — 比较次数固定为 n(n−1)/2 次（与输入实例无关） T(n) = 2n² + 3n − 4 Θ(n²)

    为什么可以忽略系数与低阶项

    3n²/2 + 7n/2 − 4 与 2n² + 3n − 4 在 n 充分大时相差不大， 原因是两函数的最高阶项相同。渐近分析的本质就是忽略 T(n) 的系数与低阶项，只关注高阶项，用记号 Θ 表示。

    七、比较排序的下界与线性时间排序

    这一组结论回答「O(n log n) 是不是极限」，以及「怎么突破它」。

    决策树模型

    • 内部节点标为 i:j（i, j ∈ {1, 2, …, n}），对应一次比较操作。
    • 左子树表示当 ai ≤ aj 时的比较序列；右子树表示当 ai ≥ aj 时的比较序列。
    • 叶子节点对应一个排列。
    • 算法的运行时间 = 路径的长度；最坏运行时间 = 树的高度。

    比较排序的下界（必考证明）

    定理：对 n 个项排序的任何决策树的高度是 Ω(n lg n)

    步骤不等式依据
    ①L ≥ n!n 个元素有 n! 种可能的排列，每种排列至少对应一个可达叶子
    ②L ≤ 2h高度 h 的二叉树最多有 2h 个叶子
    ③n! ≤ 2h ⇒ h ≥ lg(n!)由 ①② 联立，两边取 lg（lg 单调递增）
    ④h ≥ lg(n!) ≥ lg((n/e)n) = n lg n − n lg e = Ω(n lg n)Stirling 公式 n! ≈ √(2πn)·(n/e)n 放缩

    推论

    在最差情况下，任何一种比较排序至少需要 Ω(n lg n) 次比较操作。 这是比较操作所能获得的信息有限所导致的。从这个意义上讲，堆排序和归并排序是渐进最佳的比较排序算法。

    信息论视角：n! 种可能输出需要至少 lg(n!) 位信息，而每次二值比较最多提供 1 位信息。

    相邻交换的下界与希尔排序为何能突破

    定理：通过交换相邻元素进行排序的任何算法平均需要 Ω(N²) 时间

    • 排序的本质就是消除逆序数；对随机数组，逆序数是 O(N²) 的。
    • 用「交换相邻元素」消除逆序，每次正好只消除一个，因此必须执行 O(N²) 次交换 —— 这就是冒泡、插入等算法只能到平方级别的原因。
    • 要突破该下界，必须交换相隔比较远的元素，使一次交换能消除一个以上的逆序。希尔、快排、堆排都是交换比较远的元素。

    三种排序的复杂度对照

    算法是否比较排序时间复杂度空间稳定性
    堆排序 / 归并排序是Θ(n lg n)归并 O(n)归并稳定、堆排不稳定
    计数排序否（各项之间根本不比较）Θ(n + k)O(k)稳定
    基数排序否（逐位用稳定排序）Θ(d(n + k))O(n + k)稳定

    破解「矛盾」：计数排序 Θ(n+k) 与排序下界 Ω(n lg n) 冲突吗？

    不冲突。下界 Ω(n lg n) 只约束比较排序； 计数排序不是比较排序 —— 实际上各项之间根本没有比较。这正是它能达到线性时间的根本原因。

    另外计数排序是牺牲空间换时间：当 O(k) > O(n log n) 时，其效率反而不如基于比较的排序。

    计数排序的四段循环

    伪代码（PPT 原文）

    for i←1 to k                      // 循环1：清空计数数组
    do C[i] ← 0                   // 每个桶的计数置 0
for j←1 to n                      // 循环2：统计每个值出现的次数
    do C[A[j]] ← C[A[j]] + 1      // C[i] = |{key = i}|
for i←2 to k                      // 循环3：累加，得到前缀和
    do C[i] ← C[i] + C[i–1]       // C[i] = |{key ≤ i}|
for j←n downto 1                  // 循环4：反向填充（n downto 1 保证稳定性）
    do B[C[A[j]]] ← A[j]          // 把 A[j] 放到它该在的位置
       C[A[j]] ← C[A[j]] – 1      // 该位置的计数减 1

    运行时间（逐行代价）

    循环1  for i←1 to k        Θ(k)   // 与值域 k 成正比
循环2  for j←1 to n        Θ(n)   // 与元素个数 n 成正比
循环3  for i←2 to k        Θ(k)   // 与值域 k 成正比
循环4  for j←n downto 1    Θ(n)   // 与元素个数 n 成正比
------------------------------------  // 四段循环相加
合计                       Θ(n + k)  // 总时间复杂度

若 k = O(n)，则 T(n) = Θ(n)     // 线性时间
空间复杂度：O(k)                 // 额外需要一个长度为 k 的数组

    PPT 算例：A = ⟨4, 1, 3, 4, 3⟩（n = 5，k = 4）。 循环2 结束后 C = [1, 0, 2, 2]；循环3 累加后 C = [1, 1, 3, 5]； 循环4 反向填充后 B = ⟨1, 3, 3, 4, 4⟩，此时 C = [0, 1, 1, 3]。 完整逐帧过程见「L3 · 线性时间排序」页的动画。

    基数排序（LSD）

    • 思想：把整数按位数切割成不同的数字，然后按每个位数分别比较（元素级别的分治法）。基数（radix）就是「进制」，所谓「每一位」是该进制下的位。
    • 做法：① 所有待比较数值统一为同样数位长度，短的补零；② 从最低位开始依次排序。最低位排到最高位后，整个数列有序。
    • 为什么先低后高：越是后排的数位对结果次序影响越大，高位比低位影响大。必须用稳定的排序作为子过程。
    • 正确性（归纳）：假定低 t−1 位已排好，按第 t 位排序后，只需证任意两数相对位置正确 —— 第 t 位相同者靠稳定性保持原序，第 t 位不同者按该位排定。
    • 适用与缺点：适合取值很大的数、也可排字符串；缺点是不呈现时空局部性（按位排序时元素位置可能剧烈变动，无法利用缓存），且中间用的计数排序不是原地排序。

    PPT 算例：329, 457, 657, 839, 436, 720, 355 经个位 → 十位 → 百位三趟后得到 329, 355, 436, 457, 657, 720, 839。

    八、线性时间选择（第 4 讲）速查

    核心命题：找第 k 小元素不必排序——每次划分后只递归「目标所在的那一侧」，就能做到线性时间。

    情形方法代价
    k = 1 或 k = n一次线性扫描，记录当前最小/最大n − 1 次比较
    同时找最小与最大（分别独立）两次扫描2n − 2 次比较
    同时找最小与最大（成对处理）先对每对元素互比（1 次），较小者比当前最小、较大者比当前最大（2 次）3⌊n/2⌋ 次比较

    3⌊n/2⌋ < 2n − 2　（n ≥ 2）

    五种解法层次

    解法思路复杂度
    暴力对每个元素统计比它小的个数O(n²)
    归并排序完全排序后取第 k 个O(n lg n)
    快速排序完全排序后取第 k 个平均 O(n lg n)
    RANDOMIZED-SELECT随机主元划分，只递归一边期望 Θ(n)；最坏 Θ(n²)
    BFPRT（中位数的中位数）确定性选枢轴，保证划分均衡最坏 O(n)

    两个必背递推式

    RANDOMIZED-SELECT 期望：E[T(n)] = (1/n)·Σk=0n−1 E[T(max(k, n−k−1))] + O(n)， 用指示器随机变量 E[Xk] = 1/n，再用代换法证 E[T(n)] = O(n)。关键放大：Σk=0n−1T(max(k,n−k−1)) ≤ (2/n)Σk=⌊n/2⌋n−1T(k)，且 Σk=⌊n/2⌋n−1k ≤ (3/8)n²。

    BFPRT 最坏：T(n) ≤ T(n/5) + T(7n/10) + O(n)。因 1/5 + 7/10 = 9/10 < 1，几何级数收敛 ⇒ T(n) = O(n)。

    为什么 7n/10：每组 5 个、取中位数后，中位数的中位数 x 至少有 3 个元素/组大于它、3 个小于它；被确定在一侧的元素约 3(⌈n/5⌉/2 − 2)，故划分后较大子问题规模 ≤ n − 3(⌈n/5⌉/2 − 2) ≈ 7n/10。

    延伸

    把「每 5 个一组」改成「每 7 个一组」是否仍 O(n)？关键在于子问题规模系数之和是否 < 1；每 7 个一组时每列有 4 个元素可确定，划分后规模更小，仍为 O(n)（常数变大）。

    九、递归与分治（第 5 讲）速查

    递归与分治要点

    • 递归函数两个要素：边界条件（递归出口）+ 递归方程。
    • 分治三步骤：分解（Divide）→ 求解（Conquer，递归）→ 合并（Combine）。
    • 四个适用条件：① 可分解为规模较小的问题；② 子问题相互独立、不含公共子问题；③ 规模足够小时易解；④ 子问题的解可合并为原问题的解。
    • 通用递归式：T(n) = a·T(n/b) + f(n)（a 个子问题，每个规模 n/b，分解+合并代价 f(n)）。

    本讲六个例子的递归式与结论

    问题递归式结论关键点
    求幂 xnT(n) = T(n/2) + O(1)O(lg n) 次乘法偶数 xn=(xn/2)²，奇数再乘一个 x
    Hanoi 塔T(n) = 2T(n−1) + 12n − 1先把 n−1 个移到辅助柱，移最大盘，再移 n−1 个
    归并排序T(n) = 2T(n/2) + Θ(n)Θ(n lg n)合并是线性时间
    二分查找T(n) = T(n/2) + Θ(1)Θ(lg n)nlog21 = n0 = 1，属主方法情况 2
    矩阵相乘（分治）T(n) = 8T(n/2) + Θ(n²)Θ(n³)8 次子矩阵乘，没有改进
    StrassenT(n) = 7T(n/2) + Θ(n²)Θ(nlg7) ≈ Θ(n2.81)7 乘 18 加/减；n ≥ 32 时超过普通算法

    硬币问题（假币较轻，一个天平）：天平有 3 种结果（左轻 / 右轻 / 平衡），所以三分最优， 次数为 ⌈log3n⌉；二分与顺序搜索都不如三分。

    Strassen 的 7 个乘法（2×2 分块）

    P1 = a(f−h)　P2 = (a+b)h　P3 = (c+d)e　P4 = d(g−e)
    P5 = (a+d)(e+h)　P6 = (b−d)(g+h)　P7 = (a−c)(e+f)
    r = P5+P4−P2+P6　s = P1+P2　t = P3+P4　u = P5+P1−P3−P7

    验证 r：(a+d)(e+h) + d(g−e) − (a+b)h + (b−d)(g+h) = ae+bg。注意：该推导不依赖乘法的交换性。

    VLSI 布局：朴素嵌入面积 Θ(n lg n)（H(n)=H(n/2)+Θ(1)、W(n)=2W(n/2)+Θ(1)）；H-树嵌入 L(n)=2L(n/4)+Θ(1)=Θ(√n)，面积 Θ(n)。

    十、动态规划（第 6 讲）速查

    Programming 指「表格法」，不是写程序。DP 与分治都靠「组合子问题的解」，区别是 DP 适用于子问题重叠； 实质 = 分治思想 + 解决冗余（每个子问题只解一次、存表复用）。

    四步设计法（必背）

    1. 刻画最优解的结构特征（最优子结构：原问题最优解包含子问题最优解）；
    2. 递归地定义最优解的值（写出递归式）；
    3. 计算最优解的值（通常自底向上）；
    4. 利用计算出的信息构造最优解（如 m/s 表、b 箭头、l 数组、root 表）。

    DP 的两个要素：最优子结构 + 重叠子问题

    PPT 关键算例（数字要记）

    • 钢条：价格 p=[1,5,8,9,10,17,17,20,24,30]；n=4 有 23=8 种方案，最优 2+2 收益 10。
    • 矩阵链：P=(30,35,15,5,10,20,25)，最优值 m(1,6)=15125，方案 ((A1,(A2A3))((A4A5)A6))。
    • LCS：x=ABCBDAB, y=BDCABA，c[7][6]=4，LCS 为 BCBA（BDAB 也是）。
    • 装配线：PPT 算例 f* = 38，l* = 1。
    • OBST：p=[_,.15,.10,.05,.10,.20]、q=[.05,.10,.05,.05,.05,.10]，最优费用 e[1,5]=2.75。

    易错：最优子结构不是「总是成立」

    无权最短路径有最优子结构（子问题无关，不共享顶点）； 无权最长路径没有最优子结构——子问题的解甚至可能组合不成原问题的合法解（最长路径会争用顶点）。 所以「能分解成子问题」不等于「能用 DP」。

    DP 与分治对比：相同=都合并子问题解；不同=分治要求子问题独立，子问题重复出现时会重复计算；DP 专治重叠，每个子问题只解一次。贪心不行时，DP 往往可行。

    十一、贪心法（第 7 讲）速查

    贪心可行的两个要素：最优子结构（optimal substructure）+ 贪心选择特性（greedy-choice property）

    • 最优子结构：问题的最优解包含子问题的最优解。
    • 贪心选择特性：全局最优解可以通过一系列局部最优（贪心）选择得到；贪心做完选择后，只剩一个子问题。
    • 与 DP 的差别：DP 要比较多个子问题的解再合并；贪心不做回溯、不比较，因此不能保证总是最优；贪心失效时改用 DP。

    MST 的两个定理（必考证明）

    定理 1（最优子结构）

    令 T 为 G 的 MST，去掉边 (u,v) 把 T 分成 T1、T2；则 T1 是子图 G1=(V1,E1) 的 MST。

    剪切粘贴（cut & paste）：若 G1 有更小生成树 T1'，则 T' = {(u,v)} ∪ T1' ∪ T2 是 G 的生成树且权更小，与 T 最优矛盾。

    定理 2（贪心选择）

    令 A ⊂ V；若 (u,v) 是连接 A 与 V−A 的最小权边，则 (u,v) 必属于某棵 MST（简化为边权互异时属于唯一 MST）。

    证明：假设 (u,v) ∉ T。T 中 u→v 的唯一简单路径必有一条边跨越割 (A, V−A)，记它 (x,y)。把 (u,v) 与 (x,y) 交换：仍是生成树，且因 w(u,v) < w(x,y) 而权更小，矛盾。

    Prim 算法：用优先队列 Q 维护 V−A，按「与 A 中顶点相连的最小边权」排序；从任一顶点出发，每次取 Q 中 key 最小者加入 A 并松弛邻边。复杂度 O(E lg V)（二叉堆）或 O(V²)（邻接矩阵）。

    PowerPoint 算例（8 顶点）：A–B:6, A–C:12, B–C:5, B–E:14, B–F:8, E–F:3, C–D:9, C–G:7, F–G:10, G–H:15，MST 权 = 53（取 3,5,6,7,8,9,15）。

    四个贪心案例与贪心准则

    问题贪心准则结论 / 复杂度
    MST（Prim / Kruskal）每次选跨割最小边 / 全局最小边最优；O(E lg V)
    活动选择每次选结束时间最早的兼容活动最优；O(n lg n)（排序）/ O(n)（已排序）
    哈夫曼编码每次合并频率最小的两个节点最优前缀码；O(n lg n)
    分数背包按单位重量价值 vi/wi 降序装最优；O(n lg n)

    贪心失效的两个经典反例

    顶点覆盖：每次取度数最大的顶点、删去被覆盖的边——不保证最优；顶点覆盖问题是 NP 完全的。

    0-1 背包：按单位价值贪心会错。反例：W=50，物品 (v,w) = (60,10), (100,20), (120,30)，单位价值 6,5,4； 贪心得 60+100=160，而最优是 100+120=220。分数背包可以贪心，0-1 背包必须 DP。

    哈夫曼编码的度量：树 T 的编码费用 B(T) = Σc∈C f(c)·dT(c)（f 频率、dT 叶深度）； 前缀码要求任一字符编码都不是其他编码的前缀（等价于二叉树叶子）。
